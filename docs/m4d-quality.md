# M4d：数据质量规则、告警与恢复

日期：2026-09-14。当前只检查本机独立落地库和实时状态库中的虚构证券数据，不连接公司数据、生产告警或公网执行环境。

## 产品语义

1. 支持NOT_NULL、UNIQUE、VALUE_RANGE、ALLOWED_VALUES和FRESHNESS_SECONDS；资产与字段必须存在于当前可执行目录。
2. 逻辑规则引用不可变配置版本；新配置创建V2并退役V1，不能覆盖导致失败的历史。
3. 每次运行绑定规则版本、配置摘要和资产证据摘要。HTTP成功只代表请求完成，质量状态由实际检查结果决定。
4. 失败运行保存评估/通过/失败数、通过率和最多10条无效行哈希，不回显业务行；失败创建开放告警。
5. 新版本复检通过后，原告警保存recoveryRunId并转为RESOLVED；失败运行、旧版本和告警仍保留。
6. 质量Agent只看字段元数据、规则配置和聚合失败计数；模型方案经后端重新校验，人工应用只创建未运行规则。

## 测试与边界

5项新增测试覆盖失败/告警、版本恢复、未知字段/错误配置、Agent引用校验、模型行数据隔离和完整API流程；全量`npm run ci`为126/126。浏览器有效1280和768宽度均无页面级横向溢出。

M4d不是完整企业质量中心：尚无分布式调度、跨表一致性SQL、质量SLA、外部告警渠道、趋势图、影响审批或生产处置。资产标准检查与质量规则保持不同资源，不能互相冒充完成。
