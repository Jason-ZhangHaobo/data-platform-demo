# M4g：跨模块运维、事故证据与隐私门

日期：2026-09-15。当前聚合本机持久化运行，不连接公司监控、真实日志、云告警或公网多实例。

## 产品语义

1. 扫描离线同步、实时、质量、发布和数据服务失败；源运行ID为事故幂等键，重复刷新不重复创建。
2. 实时Checkpoint恢复、质量规则版本恢复和发布回滚批次自动关联为恢复证据；未找到恢复的事故保持OPEN。
3. ACKNOWLEDGED只记录谁已确认和说明，不能改变为RESOLVED。
4. 手动解除必须提交同一资源、晚于失败且状态为SUCCEEDED/PASSED的运行；其他资源或失败证据被拒绝。
5. 事故详情只返回状态、错误码、耗时和执行边界，固定`containsBusinessRows=false`。
6. 运维Agent只诊断和建议，固定`executable=false`。事故/证据ID在外发前别名化，错误原文和日志移除；但运维域、错误码和聚合状态仍按敏感上下文处理，默认禁止外发。
