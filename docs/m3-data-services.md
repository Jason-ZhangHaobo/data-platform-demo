# M3：DAPI/XAPI 数据服务

日期：2026-09-14。当前范围为本机、虚构证券数据和单项目开发身份；不是公网或生产数据服务。

## 已实现链路

1. 从状态为SUCCEEDED、由墙上时钟调度、发布且独立断言通过的Spark批次选择结果。
2. 将客户资产结果写入独立业务SQLite快照；同一快照ID不能对应不同内容，十进制金额保持字符串两位精度。
3. DAPI声明返回字段、client_id可选参数、分页、超时和每分钟限流；实际查询后保存测试结果摘要。
4. 只有当前配置哈希存在成功测试才能发布；新版本与历史版本不可变，支持版本切换。
5. XAPI固定2—5个已发布DAPI的精确版本，首版按client_id声明式合并，不执行任意代码。
6. OpenAPI 3.1描述Bearer、参数、200/401/403/429/504响应。
7. 应用授权令牌仅显示一次，平台只存哈希；相同幂等请求不重复发令牌，丢失后撤销并重建。
8. 外部调用保存服务版本、应用、参数、状态码、耗时、行数和结果摘要，不记录令牌。
9. GUI、共享V2客户端、`shuduo` CLI与`shuduo-mcp`使用同一`/api/v2`资源；旧V1接口继续明确为模拟。
10. Data Agent读取已发布资源摘要，生成DAPI/XAPI方案；后端验证资源ID、版本、字段、超时和限流，人工应用后只创建草稿。
