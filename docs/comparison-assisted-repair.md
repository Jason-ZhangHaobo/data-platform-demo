# 对照辅助 SQL 修正

更新：2026-11-09。开发结果与人工辅助交付分阶段验收；本机实现不等于已部署公网。

## 1 背景

证券工程师在客户资产加工中发现重复持仓等回归失败，需要选择同口径成功运行，理解代码与已保存核验差异，再委托 Agent 修正。对照结果是参考依据，不能自动成为正确答案或发布授权。

## 2 价值

在独立 Agent 工作台的“运行对照”中直接新建修正任务。失败运行、成功基线、双方代码摘要和证据摘要同时固定；默认只向模型发送已登记字段引用、观察条件和通过状态变化，不发送基线原 SQL、表达式、业务结果或独立预期值。当前失败 SQL 及原诊断继续沿用既有开发上下文与模型边界。

## 3 问题

- 同一代码摘要不能证明输入或断言未变。服务端对原运行、版本及来源记录重新计算证据摘要，防止只比对展示标签而遗漏变化。
- 缺少输入、断言或引擎一致性证据时，只能提供历史参考，不提供受控场景变化或因果结论。成功基线仍须具备完整独立核验及文件测试。
- 工程师引用历史代码或失败依据后，模型重写不能抹除人工辅助来源。再次新建失败修正时同样保留归因。
- 提交回执缺失不能另建任务；沿用原内容、原幂等编号和原请求查询。已完成回执也必须加载对应运行，不能只显示完成状态而结果区空白。

## 4 需求与验收

### 工作台

选择成功基线并读取对照后，显示“以该基线新建修正任务”。按钮明确委托新任务而非恢复旧任务，说明模型／Spark预算、人工辅助及发布边界。无写权、限定原任务窗口、正在执行、草稿未保存、请求待确认或环境未就绪时不可创建。独立核验或文件测试未确认的基线不可使用。

读取修正依据期间，若来源、选中基线、代码、权限或页面变化，迟到结果不能提交。依据预检不创建任务或计算。新任务使用既有提交恢复机制，先校对原始SQL、上下文、来源、对照摘要及人工辅助标记，再确认回执。

### API、CLI、MCP

- `GET /api/v2/runs/:failedRunId/repair-comparison?baseline_run_id=:baselineRunId`：分别授权两条运行，要求当前账号拥有原代码及来源；返回冻结绑定与脱敏参考摘要。只读，不运行模型、解析器或Spark。
- `POST /api/v2/agent/tasks`：原 `sourceRunId` 和精确保存SQL之外，可选 `repairComparison={baselineRunId,currentRevisionHash,baselineRevisionHash,evidenceDigest}`；不接受客户端提供摘要、诊断替换、口径派生或不同SQL版本混用。沿用邀请权限、任务窗口、原幂等编号和预算门槛。
- `shuduo agent repair-basis --source-run-id FAILED --baseline-run-id SUCCESS`：只读核对。
- `shuduo agent repair-compare --source-run-id FAILED --baseline-run-id SUCCESS --message "修正证券SQL" --request-id UUID --confirm`：明确委托后提交。未知结果用 `shuduo agent request --request-id UUID` 查询；不能换编号自动重试。
- MCP：`agent_repair_comparison_basis` 与 `agent_repair_comparison_create` 共用同一接口。创建工具必须提供 `confirm:true` 和原请求编号，不代表发布批准；本地处理器测试不等于外部客户端注册与接通。

### 执行与归因

创建、模型调用前、模型返回后及新计算入队前重核保存依据。证据变化后拒绝新计算；已经发生的模型调用仍保留用量，不退款、不重置尝试。已提交运行仍可查询原回执，不能因后续参考变化而自动重复计算。

首次调用接收对照摘要；后续自动修正使用新失败运行反馈，历史依据保持冻结，不冒充当前代码对照。持久与本机旧执行器均支持此流程。

任务、代码、运行和独立生成文件均保留人工辅助归因，不计当前完整E2E自主完成率；文件清单沿用 `ENGINEER_ASSISTED`。原生 Agent 自动交付入口拒绝辅助修正结果。**人工辅助交付的文件演练、确切版本审阅与发布适配是下一阶段，不能用本轮创建开发任务替代。**

验收包括：归属／CSRF／字节摘要／基线证据、隐藏运行证据变化、调用前后漂移、用量保留、原编号恢复、只读迟到、重复提交、CLI／MCP一致性、错误回执隔离及辅助归因无法升级为自主。

## 5 Demo

使用虚构证券账户、现金和持仓。当前SQL省略持仓记录去重，标准样例通过而重复持仓回归失败；选择已通过五场景与文件测试的同口径基线。Agent只接收已核验参考摘要，生成新版本后重新执行独立核验。

本机界面验收复用已保存真实Spark对照，新增模型／计算使用明确标注的合成回执；验证响应不完整后查询原请求、刷新保留同一任务与结果。该演示不证明真实模型修正率、云端部署、发布成功或完整生命周期E2E完成。
