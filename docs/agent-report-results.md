# 独立Agent会话中的同源资产报表

独立开发工作台的核验与交付区域新增报表结果视图。原生Agent本机发布和固定来源的本机手工交付共用视图；只读查看已有聚合结果，不创建数据集、调用模型、运行SQL或重新生成报表。

视图只匹配当前确切发布的已成功调度批次，随后核对数据集快照的实际来源批次、固定报表版本、配置摘要、聚合运行及内容摘要。它不把目录中的全局最新资产当作当前任务结果；数据集刷新后，历史版本仍按自身快照读取。手工来源不补造Agent关联，也不计自主完成。

用户可在同一会话查看总资产、持仓、现金及客户分布，重读记录或导出同版本CSV。缺类别／行业字段继续明确提示。CSV导出先核对报告、版本、运行及SHA-256；历史运行不再是当前可导出版本时关闭导出，不替换为另一版。此项复用既有`/api/v2/reports/overview`及报表`export`资源，不引入新权限或绕过既有授权。

读取失败保留同源历史作对照并关闭导出，明确显示未确认；有效回执没有匹配批次时明确无此来源报表，不展示其他任务结果。源版本切换及卸载后的迟到响应不能覆盖新来源。当前云端发布尚未接入此结果视图，不把本机视图算作公网报表验收。

## 验收范围

- 原生Agent来源、手工归因、固定历史快照、版本／摘要错误、导出替换及内容篡改由合成测试覆盖。
- 实际界面复用既有MANUAL参考SQL的真实Spark发布结果与已保存报表，验证会话内图表、金额、脱敏、同版导出、错误回执／其他批次拒绝及恢复。传输故障是合成的；原审阅仍是合成测试审阅，不是本人业务批准。
- 18次只读请求，原16类业务记录数量不变，没有新增模型、Spark或云操作。完整CI1595项：1594通过、0失败、1既有跳过；类型、构建及入口体积门通过。

下一步补“从此确切发布批次创建报表”流程。必须在服务端固定来源与权限，形成真实快照和聚合运行，再回到同一结果视图；不能仅把按钮或模板方案当成完成。当前真实模型／公网／20例及完整经典能力仍按[总目标清单](goal-acceptance-audit.md)分别验收。
