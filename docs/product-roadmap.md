## M0 已核对事实
- 旧后端为 Node.js，元数据写入 OSS 单 JSON；不适合直接当作多用户生产库。
- 旧 Agent 使用关键词路由；旧质量/报表/实时指标多数预设；旧发布没有实际调度执行。
- 当前开发机可运行 Node.js 24、Java 17/Python 3.12/Spark 3.5.7，通过 29 项引擎/交叉核验检查；未安装 Docker。
- 模型凭证已保存，真实 Qwen 调用、Spark 报错反馈和自动修正已执行；失败和验证范围升级记录见 [真实试跑报告](m1-live-agent-report.md)。
- 当前云资源实际账单、域名、备案未验证；不能把一次代码试跑推定为模型整体能力达标。
- UI 为大标题/长横向导航；V2 改为按工作组织的侧栏与开发工作台。
