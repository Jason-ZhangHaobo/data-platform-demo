# 手工成功 SQL 交接给 Agent

更新：2026-11-09。本机协议与页面验收；真实模型、真实云端执行和完整生命周期E2E仍需独立验证。

## 1 背景

证券数据开发工程师先在经典编辑器保存、运行SQL，再让Agent修改代码，是常见协作路径。此前成功版本续改要求已有成功Agent任务；没有原任务的手工版本无法交接，或可能经通用创建丢失手工来源。

## 2 价值

直接从本人保存并完整核验的SQL创建新的Agent任务。无原Agent时不虚构父任务；有人工接管关联时保留原任务历史。原代码、运行、结果及用量不变，新任务记录人工辅助来源，独立生成、核验、交付和审阅。

## 3 问题

- SQL执行成功不等于可交接。需要保存代码摘要、本人手工来源、同项目／同口径运行及五场景独立结果。
- 读取与生成期间来源可能变化，不能继续使用过时证据；已发生的模型用量不能退款或清零。
- 没有原Agent任务的手工代码不能冒作“失败修正”或虚构成功父任务，也不能被计入Agent自主完成率。
- 本机登录用户的保存作者、原保存请求查询和Agent执行者需要一致；匿名本机身份仍仅用于本地开发，不自动领取其他身份的旧版本。

## 4 需求与验收

### 使用流程

恢复手工成功版本后，工作台显示“继续完善这份手工SQL”和“基于手工版本修改并验证”。工程师输入修改意图，页面预检原版本与运行，再按稳定原请求创建独立任务。

Agent只取得新意图、所选业务定义和手工SQL，不复制原错误、结果、付费尝试、交付包或批准。新代码完成自己的执行及独立核验后，可进入现有MANUAL文件演练和确切版本审阅；之后仍可使用成功辅助任务续改协议，原始手工成功根继续保留。

本轮交接要求持久Spark SQL与同一已登记口径，不接受Python或其他来源混用。脏代码、错批次、权限不足及限定原任务窗口不得创建新任务。[独立手工文件／演练](standalone-manual-delivery.md)已继续补齐，无需假的Agent历史；独立手工云发布仍为下一阶段。

### 接口

- `GET /api/v2/runs/:runId/manual-continuation`：核对本人手工版本及成功结果，只读返回上下文、冻结绑定与开发参考，不调用模型或计算。
- `POST /api/v2/agent/tasks` 可选 `manualContinuation={kind,revisionId,runId,revisionHash,evidenceDigest,originAgentTaskId?}`，`kind=MANUAL_SUCCESS_CONTINUATION`。可选关联必须与原保存记录一致，不是请求替换来源；执行人始终来自后端会话。
- 输入SQL保留已保存字节，上下文必须相同；不得混用失败来源、对照、Agent父版本或口径派生。无持久SQL引擎时明确拒绝，不退回无来源普通任务。
- CLI：`shuduo agent manual-continuation --source-run-id RUN`只读；`shuduo agent continue-manual --source-run-id RUN --message "完善已核验证券SQL" --request-id UUID --confirm`明确委托。
- MCP：`agent_manual_continuation_read`与`agent_continue_manual`共用上述API；创建需原请求编号及明确确认。未知回执先查询原请求，不自动重试。

### 来源与恢复

核对代码作者、`ENGINEER_EDIT`来源、项目、代码／运行摘要、上下文、真实Spark标识和独立五场景结果。关联原任务可为空；有值时须属于本人同项目及同口径SQL历史。创建、模型前后及新计算入队前重核，变化时不新增计算，已发生用量和原失败历史保留。

开发参考增加 `MANUAL_SUCCESS_REFERENCE`，保存手工成功运行、原代码摘要、证据摘要和可选原关联任务。新任务／版本／运行标为 `MANUAL／ENGINEER_ASSISTED`，代码生成仍是 `LIVE_MODEL`；根引用进入新包摘要，不能升级为原生或继承批准。

原请求恢复须核对修改意图、SQL、上下文、绑定和归因后确认；刷新只读恢复同一任务与演练。本机登录后的保存与原请求查询使用会话作者，与SQL Agent一致；未登录本地开发才使用 `local-engineer`。

验收覆盖独立与接管来源、经典保存／运行控制器、作者一致、CSRF／其他管理员、字节／上下文／来源混用、证据漂移、已发生用量、错误回执、原编号、CLI／MCP、后续来源链和新包独立。

## 5 Demo

使用虚构证券账户、持仓和现金SQL。工程师已在编辑器保存并核验成功，再请求“补充注释、保留证券指标口径”。原手工记录保留，只新增一个Agent任务；模型、执行与文件演练使用合成回执验证原编号恢复及独立交付。

本机协议验收不代表新增真实模型／Spark执行、真实云部署或当前20例完整自主E2E。手工代码交接的结果始终属于人工辅助，不能用来填充自主完成分子。
