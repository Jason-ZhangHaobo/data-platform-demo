# 证券报表的实际字段与指标范围

报表默认模板按所选数据集的真实字段生成，不因发现一个金额字段就假设其他维度存在。已有报表版本保持原配置；本次修正用于后续手动创建的默认模板，不改写历史版本或模型方案。

| 已有字段 | 可生成组件 |
|---|---|
| total_assets | 客户总资产合计；同时有client_id时生成各客户总资产 |
| holding_market_value或market_value | 持仓市值合计，优先使用已加工的holding_market_value |
| available_cash | 可用现金合计 |
| security_code | 证券代码去重数 |
| security_count、client_id，且无security_code | 各客户证券数量，提示先确认每客户一行，跨客户合计不能当全局去重数 |
| 持仓金额及asset_class／industry | 对应资产类别／行业分布；缺字段明确提示，不补造维度 |

金额标明元，持仓市值不冒充总资产。只有客户级五字段结果时默认生成五个组件：总资产、持仓、现金、各客户证券数量、各客户总资产。字段提示是模板说明，不替代业务粒度、重复行或实际引擎质量校验。

已在隔离本机复用先前实际Spark发布结果，通过数据集物化、固定快照、实际聚合、独立金额断言和CSV核验。报表版本、运行和导出对应同一快照；客户展示脱敏。只读界面查看与导出没有新增版本、运行、调用或计算。首次验收脚本误把运行API的报表详情回执当作嵌套运行对象，已保留失败，按原编号只读续接，未重复创建或聚合。
