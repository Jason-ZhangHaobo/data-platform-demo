# 分布发布结果的 DAPI／XAPI

本增量只适配本机虚构证券结果，不开放私有云或公网分布写入，不新增计算引擎。证券持仓资产类别与行业两类登记契约共用同一管理器、HTTP API、版本、应用授权及调用日志；旧五列客户资产查询保持原行为。

## 粒度与响应

DAPI 始终返回 `client_id`、`trade_date`、登记分类字段（`asset_class` 或 `industry`），另选市值／证券数量、占比或全部字段。按三个键的二进制顺序稳定分页，`pagination.total` 是明细行数。金额固定两位、占比固定六位，均为十进制字符串；证券数量为安全整数。不拼入现金或客户总资产。

XAPI 仅组合相同登记契约、同一发布批次、同一不可变快照的 DAPI 固定版本，先按完整复合键关联，再返回 `{client_id, trade_date, distributions:[{分类, holdings:{…}, allocation:{…}}]}`。每页单位为客户＋交易日，分类数组不会跨页截断；子查询最多各1000行，缺行、重复键或分组不一致即失败，不退回按客户覆盖的旧合并逻辑。

响应附 `resultContract`，说明契约、键与分页单位；OpenAPI 描述准确的数组及十进制字符串结构。查询参数仍为 `client_id`、`page`、`page_size`，未知参数和越界分页拒绝。新版本不能隐式切换为旧粒度，XAPI 不跟随子接口的新草稿或新版发布。

## 来源与安全

创建分布快照前核对原需求／代码／包、独立文件审阅、确切计划批准、两个当前成功调度批次、八文件哈希、测试SQL、五场景结果、监控事件及独立业务预期。缺失或发生变化时不提供来源，不用其他任务顶替。数据快照和平台元数据分开保存；新增可选快照表兼容旧v1状态，读取会复核契约、行数及内容摘要。

“可查询已验证结果”与“真实模型自主完成”分别判定。允许本机已执行结果的上游为模型替身，但必须保留 `SYNTHETIC_UPSTREAM`／`TEST_HARNESS` 等来源分类和 `agentIndependentE2E:false`；不能把模型名或本机回执当提供方真实性证明。旧来源核验器与真实完整E2E计分规则不放宽。

复用现有 DAPI／XAPI 创建、版本、测试、发布、OpenAPI、应用发放／撤销和调用日志端点，不另建绕过权限的入口。Agent 的原任务／包／发布交接入口只导航，不自动发布、发凭证或调用；分布消费尚未接入旧五列消费汇总及完整E2E自动计分，页面明确标记。

## 验收入口与边界

合成回归见 `test/v2/distribution-services.test.mjs`、`distribution-consumption-api.test.mjs`、`data-state-replica.test.mjs` 和 `service-composition.test.mjs`：资产类别／行业、复合键、精度、快照损坏、重开、旧状态兼容、同批组合、完整数组分页、固定版本、授权／越权／撤销及调用摘要。

实际本机结果与界面证据保存在受保护状态，不进入公开仓库。实现、源码CI、实际部署、本机业务验收和真实模型完整E2E分别记录。后续优先完成同源分布消费回执／恢复与完整旅程展示，再在本人材料及新有效窗口具备后开展真实模型／云端验收。
