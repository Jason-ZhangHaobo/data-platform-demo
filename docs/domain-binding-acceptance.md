# HTTPS 域名接入验收合同

本文件是实施合同，不是云端已部署或公网已上线的证明。当前授权、证书和实际域名配置只读取受保护执行状态。

## 一次接入批次

1. 核验受保护 main 的固定版本、原角色与策略、原函数代码及关闭的业务开关、预算和剩余授权窗口。
2. 复用原验收检查点，仅在明确批准下重建同名签名 HTTP 临时入口一次；保留既有调用计数，不用新批次清零额度。先完成默认入口的隔离验证。
3. 在同一个临时入口仍存在时，核对域名未配置、DNS 无冲突、证书匹配后，只新增批准的根 CNAME 与 HTTPS 绑定。域名仍使用云签名认证，应用公开业务开关保持关闭。
4. 核验实际 TLS 和自定义域名隔离。默认域名与自定义域名分别记录请求计数；不运行模型、Spark 或发布任务，不用网关鉴权失败代替已签名请求到达应用后的隔离证据。
5. 成功仅保留批准的域名配置；失败只回滚本次创建且内容仍匹配的配置。统一清理临时 HTTP 入口、临时加密 Secret 与临时 IAM 条款，并回读确认。

该批次不包含匿名业务开放、受邀用户实际使用验收、自动续期或新增计算任务；完成后不能宣称公网产品已可用。

## P0-B阶段衔接与固定配额

签名HTTPS是P0-B的首道接入门，不替代最终受邀公网访问。后续仍必须完成实际登录、项目隔离、会话退出/失效，以及经安全门批准的业务开放；只有完整要求通过才能标记P0-B完成。模型/Spark就绪及完整用户链路另以真实结果验收，不能延长旧就绪证据或以接口200代替。

新阶段使用独立的`P0B_SIGNED_HTTPS_17_PLUS_23`授权标识；旧授权不自动扩额。保留历史17次，默认入口固定新增15次（1次私有状态与14个边界对照），域名固定8次，合计最多40。配置必须引用受保护的前序控制面验收编号及证据摘要，由本机协调器验证来源、当前代码和清理结果后提供，不能清零历史计数。

仅恢复同名签名临时入口一次、创建一个本域名绑定和一条根CNAME；域名元数据读取最多10次，创建/必要回滚删除各最多1次，未知写入先按检查点回读，不重复创建。预算预留2元、月度上限200元，时间窗最多1小时。默认及域名边界均先验签名正向基线；任何失败均保留原报告并按所有权规则清理。

DNS交接先等待权威服务器发布精确CNAME，再确认普通公网递归解析，避免在写入前缓存否定应答。权威结果不能替代公网解析或TLS；不修改hosts、不替换连接IP。新阶段DNS等待最多12分钟，绑定步骤最多18分钟、整个云作业最多40分钟，仍受原1小时授权和清理预留约束；超时即保留失败并清理，不自动创建第二条记录或新入口。

### 显式批准的一次修复续跑

`P0B_SIGNED_HTTPS_RESUME_32_PLUS_23`为独立授权标识，不接受原授权替代。它只支持已完成默认入口验证、域名创建未获确认且已回读不存在的首批：历史固定32、默认新增15（累计47）、域名8，最终累计≤55，不能改变参数清零或无限续跑。原17＋23与旧20次额度均保持原值。

受保护协调器须解密原始证据并核验原作业/源码、目标/操作编号、请求计数、域名不存在、DNS已移除及临时IAM/Secret/入口已清理；无法证明任一项就拒绝。云端再次验证原函数和原OSS触发器的完整摘要，基线改变时在私有调用和入口创建前停止。一个新固定检查点目录仅可启动一次；存在检查点只允许核对/清理，不存在自动第三次续跑。

一次续跑仍限同名临时入口1次、同域名创建1次、根CNAME1条，域名元数据10/1/1，权限≤1小时、当批预留2元/月≤200元；另保留前序6元未结算预留。原冻结业务代码、环境与容量不变，模型/Spark为0。实现和测试不代表批准已取得或云端已执行，是否启用以实际人类答复为准。

### 仅剩余域名检查

`P0B_SIGNED_DOMAIN_47_PLUS_8`是另一个默认拒绝的明确授权范围：只继承最近一轮已完成的默认入口验收，保留47次历史，不再执行私有状态调用或默认地址HTTP探测，域名8项后累计仍≤55。旧32＋23范围不能自动切换到本模式。

协调器必须解密并验证两轮原始证据链及其来源、计数、清理和目标；最新一轮必须记录明确的TLS参数拒绝、域名不存在且域名探测为0。云端读取当前函数/原OSS触发器全配置摘要，核对冻结代码、私有业务开关、容量与预算后，才创建一次同名签名临时HTTP入口。该入口是自定义域名实际调用所必需，不把删除触发器后的绑定称为可用产品入口。

交接报告明确标记`SIGNED_DOMAIN_PREPARATION_ONLY`、`defaultBoundaryReused:true`、原作业/证据摘要、`newRequests:0`及空的新结果数组；不能复制旧结果冒充新15项通过。报告与检查点必须同时仍为47次，且整个批次不调用默认地址。之后复用既有DNS交接、8项域名真实TLS/安全检查和失败回滚/统一清理。前序费用预留8元、本批2元，仍需当前月≤200元。

此模式不允许重复清零、第三次自动继续、开公网业务或更改函数代码/环境；必须收到对应人类批准后才能启动。同一固定检查点存在时只恢复原查询/清理，不新建作业。

## 最小权限与密钥处理

- 按 FC 3.0 官方 API 授权表，`GetCustomDomain`、`CreateCustomDomain` 的资源为 `*`；该技术权限可能作用于其他域名，必须明确告知并限制使用范围和有效期。
- `DeleteCustomDomain` 支持具体 `acs:fc:<region>:<account>:custom-domains/<domain>` 资源，回滚删除不授予账号级通配权限。
- 不申请 `UpdateCustomDomain`；遇到已有域名、DNS 冲突或外部配置变化即停止，不自动接管、更新或删除。
- 证书私钥仅由本机受保护目录通过临时加密 Secret 交付到已核验的 FC TLS 配置。不得出现在命令参数、日志、报告、Git 或 Artifact 中；临时 Secret 在结束后删除。本机原私钥保留用于管理证书。
- 证书主体、SAN、有效期和私钥匹配必须校验；签发验收中的受信任链检查以及实际 HTTPS 信任链检查不能由“证书文件存在”代替。
- TLS版本限定1.2—1.3，`cipherSuites`仅发送官方组件`ITLSConfig`枚举支持的四个ECDHE/AES-GCM套件（RSA/ECDSA各两项）。`TLS_AES_128_GCM_SHA256`和`TLS_AES_256_GCM_SHA384`属于TLS1.3支持表，但不在该可配置字段枚举中，不能混填；TLS1.3通过`maxVersion`保留。不省略套件，不选择包含弱算法的“全部套件”。回读允许顺序变化，但必须与申请集合严格相同；缺失、增加、重复或降级均拒绝。Schema对齐仍不替代实际云回读和可信TLS连接验收。

## 可恢复及错误边界

- 已创建绑定的清理恢复复用原工作流的`INSPECT_EXISTING`/`ROLLBACK_EXISTING`模式，默认`NONE`。必须绑定原操作、配置摘要、基线不存在证据、加密回执摘要及原到期时间，并继承已消耗的域名元数据计数；不重置窗口或额度。恢复分支跳过入口创建、DNS交接、绑定创建与全部HTTP探测，只允许一次受控读取或归属校验后的原对象回滚。
- 读取诊断只输出字段结构、期望值匹配布尔值和允许列出的TLS信息，证书/私钥/身份标识不进入报告，最终仍加密导出。结构差异不能直接解释成安全漂移，也不能据此跳过所有权检查；无法证明属于原操作时仍拒绝删除。
- 操作编号、期望配置摘要、基线不存在证据必须在首个写请求前持久保存；无法写检查点就不创建资源。
- 创建响应未知，按原域名和唯一证书配置名称回读。内容完全匹配才继续，不发第二次创建请求。
- 创建返回明确错误且回读确认不存在时，保留`DOMAIN_CREATE_REJECTED`及限定HTTP状态、错误码、固定诊断类别，不吞掉创建回执再笼统报告失败。提供方完整错误文本、证书、私钥和输入参数不得写入证据；失败仍计入原创建次数，不自动重试。
- 删除响应未知，只回读。未证实删除时保留失败状态，恢复不盲目再删。
- 恢复成功保留的配置只读核验，不重建、不重新计算验收次数，也不冒充新的验收成功。
- HTTP探测先验证签名正向基线能到达应用，再测试未签名拒绝；时间头按官方ACS3示例只使用`x-acs-date`，不混入旧`Date`。普通`InvalidArgument`不算鉴权通过；仅未签名负向对照的400、该错误码以及精确空认证错误格式同时匹配，才识别为认证拒绝。非空认证、日期错误、含额外说明的模糊消息与签名请求的400都不得继承该结论。
- 配置漂移时拒绝清理，并准确报告未完成项。不能为消除清理错误而删除别人的资源。
- 路由比较允许服务端回填的`accountId`（未填写/null/空字符串，或严格为同一账号）和`rewriteConfig:null`（等同未配置重写）；域名级账号仍必须严格匹配，任何非空异主、空白字符串/数值0、非空重写对象、未知字段、方法/路径/函数/版本变化均拒绝。证书指纹和唯一证书配置名等所有权条件不放宽。回滚时复用同一次GET保存脱敏字段状态，不额外读一次；该规范化不改变原请求/配置摘要或授权再次创建绑定。
- `accept-v2-https-binding` 工作流将原临时入口生命周期、证书传输与域名状态机连接起来：默认入口通过后导出加密回执，本机受控协调器核验来源才写DNS；云作业观察精确CNAME后继续。`always`步骤清理原入口、回滚未通过域名并导出密文，协调器最后恢复IAM和删除临时Secret。合成测试通过不等于真实执行成功。

## 代码与测试

- `scripts/v2-domain-binding-plan.mjs`：证书校验、固定范围计划、临时策略、域名配置比对及适配器驱动的创建/回滚状态机。
- `test/v2/domain-binding-plan.test.mjs`：使用本机生成的虚构证书和内存适配器；不读取真实密钥，不创建云资源。
- 既有入口验收继续使用 `scripts/accept-v2-http-boundary.mjs`；不得单独执行后删除入口，再为域名偷偷新增第二个入口。
- `scripts/accept-v2-https-binding.mjs`与`transport-v2-domain-signed.py`：仅固定域名/操作，PEM通过stdin而非命令参数传递，响应投影删除私钥。域名探测核对可信TLS连接的实际叶证书指纹；计划通过不代替真实连接。
- `test/v2/https-binding-workflow.test.mjs`及既有线级HTTP回归覆盖阶段顺序、相同入口延续、精确鉴权拒绝和敏感响应剔除。

## 独立定向诊断

无法归类的网关错误先使用独立的`diagnose-v2-http-gateway`工作流，不直接重跑完整接入。该入口须另获明确授权，限制为三个固定GET：签名基线、未签名且带现代时间头、未签名且不带时间头；不调用内部状态执行接口，不修改DNS、域名或业务函数。历史计数保留，`boundaryAccepted`始终为false，取得诊断资料不等于安全验收通过。

默认探测不保留错误说明。显式诊断模式仅保留有界、脱敏的网关错误字段，删除凭证、URL、账号长标识和邮箱，不保留完整响应正文，且只导出加密Artifact；普通作业日志不输出诊断内容。原临时入口清理、函数/OSS触发器不变和权限撤销仍须有回执。
