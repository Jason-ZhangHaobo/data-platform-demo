# 域名接入只读核验

`audit-v2-domain-readonly.yml` 是受保护main上的手动只读入口，用于核对获准域名是否已配置、HTTPS证书是否存在及路由是否指向当前控制面。它不创建域名、证书、DNS、触发器或计算任务，也不自行修改RAM权限。

执行前必须有具体人类授权、已审查main SHA、最长一小时的截止时间及证据接收公钥。当前域名白名单仅允许项目正式域名。一次作业只发一次GetCustomDomain，无自动重试；本机协调者负责跨作业累计次数、临时权限启用和恢复，不能以再次dispatch重置获批次数。

目标账号、角色和函数标识通过临时加密Environment Secret传入，准备步骤先掩码再导出所需字段；不在工作流日志打印普通Variables值。这里只包含部署标识，不加载模型、数据库或业务密钥。使用已有OIDC角色和短期凭证，身份不符时不发域名请求。

域名读取API可能返回证书及私钥。执行器只在内存中提取状态布尔、协议和路由数量，不保存或输出证书正文、私钥、目标函数名、路径或原始响应；最小报告仍使用接收者公钥加密，并绑定源码SHA与运行编号。域名不存在是已核实的缺项，AccessDenied或未知结果不能记作不存在。

域名请求使用项目既有固定版本的官方ACS3签名库，直接读取HTTPS状态与允许列出的错误码，以免CLI错误封装丢失失败类别；身份核验仍使用既有CLI。保留原请求次数，切换传输不能重置审批窗口或获得更多调用额度。

域名不存在或读取成功不代表网站已经上线；后续DNS、证书、入口隔离和受邀访问按各自范围验收。具体权限、执行次数、云结果及恢复证据只保存在受保护状态。

测试入口：`test/v2/domain-readonly-audit.test.mjs`，涵盖目标/身份/截止时间、单请求、敏感字段剔除和动作版本固定；测试替身不证明云读取已执行。
