# Agent核验与交付工作流读取

工作台在展示前核对工作流响应，错误不当作正在加载或成功。报告必须属于原任务及口径，核验项结构完整；交付、包、源代码、源运行与演练编号必须相互对应。工程师接管保持MANUAL及非自主归因；冻结返程还要求原版本、原批次、原包与运行环境对应。

同任务其他版本的报告可以作为历史对照，不替当前编辑版本证明完成。切换任务／人工来源／代码／批次／冻结返程后，前一来源的缓存立即退出当前视图；迟到响应及卸载后的响应不覆盖新来源。核验、文件、发布与消费继续分别按各自证据判断。

SQL包只支持既有八文件规范。浏览器核对清单摘要、各文件UTF-8字节数及SHA-256，以及清单源运行／版本／口径／契约与报告对应，沿用单文件250KB、总750KB上限。不执行SQL、解析部署适配器或替代后端完整包校验；散列完整性不是审批、签名或真实执行证明。

首次null、错误对象、缺核验项或不匹配来源显示明确错误及只读重读入口。已有合法回执时保留原报告和文件供对照，关闭准备、审阅发布及后续接管；成功重读后才重新判断当前状态。读取错误不新建任务、不再演练、不自动批准。准备回执等待期间切换来源，也不能继续驱动原来源的新步骤。

本机验收包括45项相关定向回归、真实HTTP投影兼容及实际浏览器：正常八文件、首次null恢复、保留旧文件、缺核验项／错任务／篡改字节拒绝、发布入口关闭和恢复、跨批次迟到回执拒绝。完整CI1576项：1575通过、0失败、1既有跳过。任务、引擎、演练、发布能力与故障均为合成，包文件由实际生成器生成；没有真实模型、Spark、云部署或完整E2E计分。
