# 成功辅助版本的对话续改

更新：2026-11-09。状态：本机协议与交互验收；真实模型、云端部署及完整生命周期E2E另行验证。

## 1 背景

证券工程师完成一次包含人工参考的SQL修正后，常会继续提出注释、结构或计算要求的调整。此前通用新任务入口只绑定失败批次；成功后再次聊天可能丢失原始人工参考标记，也不能清晰区分父版本与新版本的文件和批准。

## 2 价值

工作台可基于当前已核验成功的持久SQL辅助任务发起新委托，父任务、代码、运行和原参考链保持可核对。新任务独立记录尝试与用量、重新计算和交付，不修改父任务或继承原包、演练及发布批准。原始来源继续标为人工辅助，不计自主完成。

## 3 问题

- 成功标签不足以证明可续改。必须核对本人、项目、持久SQL模式、最后成功尝试、代码字节、运行摘要与五场景独立结果。
- 父运行或参考依据可能变化。应在新委托、模型调用前后及新计算入队前重核；已发生的模型用量仍保留。
- 续改创建的回执未知时不能用新编号或新文本重试。原请求查询须找回同一子任务，之后输入的其他需求保留为未提交文本。
- 参考链需要限制读取工作量并防止循环。不能通过多次续改洗掉人工归因，也不能无限递归祖先。

## 4 需求与验收

### 用户流程

在当前成功辅助任务的聊天区输入修改意图。服务端只读核对父任务、版本、运行和证据，页面展示操作中状态；确认依据后按原请求机制创建独立子任务。新任务展示父任务／版本和续改深度，可只读返回父任务。

新代码经过自己的执行与独立核验；成功后生成自己的八文件交付包并演练。折叠依据同时显示直接父版本和原始失败／可选基线。父任务、文件和批准不变，新版本仍需独立审阅。

未保存代码、历史批次与当前版本不一致、限定原任务窗口、权限或环境未就绪时不可创建。尚未形成可引用来源的人工任务不能退回无来源通用创建；手工保存的成功SQL已通过独立[手工交接协议](manual-success-continuation.md)承接，不借用成功Agent父绑定；原代码和运行保留。

### 原子能力

- `GET /api/v2/agent/tasks/:taskId/assisted-continuation`：本人成功版本预检；不解析、调用模型或计算，不返回原始SQL、数据行或批准。返回上下文、父绑定和开发参考。
- `POST /api/v2/agent/tasks` 可选 `assistedContinuation={kind,taskId,revisionId,runId,revisionHash,evidenceDigest,depth}`，其中 `kind=ASSISTED_SUCCESS_CONTINUATION`。SQL须与父保存字节一致，上下文保持相同；不得混用失败来源、对照、口径派生或Python。仅持久SQL引擎接受该路径，旧引擎不回退为普通任务。
- CLI：`shuduo agent continuation --id TASK` 只读；`shuduo agent continue-version --id TASK --message "继续完善证券代码" --request-id UUID --confirm` 明确委托。未知结果沿用 `agent request --request-id UUID` 查询，不自动重提。
- MCP：`agent_assisted_continuation_read` 和 `agent_assisted_continue` 共用同一接口；创建需稳定请求编号与明确确认，执行人由后端会话决定。本地处理器一致性不等于外部客户端注册接通。

### 来源与恢复

新任务保存父绑定与 `MANUAL／ENGINEER_ASSISTED`，模型生成来源仍为 `LIVE_MODEL`。不复制父运行、版本指针、结果、错误、付费尝试或批准；第一次生成只使用新需求和当前父SQL，后续失败按新运行反馈修正。

开发参考增加 `ASSISTED_CONTINUATION`：直接父任务／运行／代码／证据摘要、深度和原始参考。原始参考只允许失败或对照根节点，不嵌套续改对象；服务端逐级验证，最多16级，超限或循环明确拒绝，未创建新任务或预留模型用量。该引用进入新包摘要，与任务、演练和MANUAL审阅继续核对。

界面在依据请求返回后再次核对来源、代码、输入和权限；创建回执须匹配原消息、SQL、上下文、父绑定及人工辅助归因，再确认原编号。恢复只查询原任务，确认继续后才推进；不会用后来输入的文本替换原请求。

验收覆盖：归属／CSRF／限定任务、代码字节和上下文、混用来源、父证据漂移、用量保留、未知回执、16级及循环、连续续改、源包不变、新包独立、CLI／MCP一致性和父子导航。

## 5 Demo

虚构客户资产SQL已修复重复持仓问题。工程师提出“补充注释，保留证券指标口径”，产生新任务、新代码和运行，并重新生成文件演练；可以查看父版本及原始参考。

本机交互使用合成模型、执行和文件演练回执，验证一个子任务、一次模型调用及两次计算提交（新代码与新文件演练），原父任务／包不变。真实Spark执行器复用既有已核验底座；本轮没有新增真实模型、真实Spark或云发布，不能计入当前20例完整自主E2E。
