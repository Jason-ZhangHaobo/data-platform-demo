# Agent工作台任务与运行读取

任务历史、所选任务和运行回执分别确认。历史必须是完整数组，每条有合法UUID、正整数版本、需求、口径和状态；重复编号、错误对象、null和不完整行整体拒绝，不静默筛除后展示空列表。只有明确回读的空数组才是空历史。错误保留当前任务、列表与未保存代码，刷新只重读，不新建或执行任务。

原任务链接先恢复所指任务，再读取可选历史。历史失败不阻塞已读任务；身份或视图离开后的迟到响应忽略。旧Python记录保持可发现，不把它改写为SQL任务。

任务详情在替换前检查原编号与可展示字段、尝试及诊断结构。任务切换后，运行回执必须对应所请求批次、代码版本和口径；回执具备所属任务时也核对归属。新运行读取中或失败时不显示上一个任务的结果，明确展示“运行结果未确认”，保留已读代码并可重读原任务与运行。

查看旧尝试同样核对确切批次、对应代码和当前任务归属；修正依据可能来自另一个任务，因此按原引用编号及同一口径读取，不冒充当前尝试。查询晚到不能覆盖离开后的新选择。编辑器保持当前代码，历史结果始终标出自己的版本；查看不提交模型或Spark。

本机证据：21项相关定向回归；完整CI 1567项，1566通过、0失败、1既有跳过，类型、构建与入口预算通过。实际浏览器核验错误任务编号拒绝、错批次拒绝、运行读取失败及恢复、旧尝试／修正依据查看、错误历史恢复与SQL草稿保留。任务、运行及传输故障均为合成，元数据使用隔离SQLite；不计真实模型、Spark、云部署或完整E2E。
