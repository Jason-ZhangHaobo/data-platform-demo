# M2a：版本化交付包与真实本机文件演练

日期：2026-09-14。适用范围是已通过当前五场景核验的证券资产 SQL。
本阶段由平台标准生成器创建文件，使用本项目运行器执行；不是模型编造的云配置，不是已适配 DataWorks/EMR，也不是已发布上线。
本文件冻结M2a完成时的状态；后续本机审批、计时发布、监控与回滚见[M2b/M2c报告](m2b-m2c-local-release.md)，仍不代表公网部署。

## 入口与用户旅程

进入 [调度与交付工作台](http://127.0.0.1:3100/v2/?module=schedules)：

1. 选择已通过当前验证范围的源运行，填写交付名称并生成包。
2. 查看 SQL、测试、调度、部署、日历与清单；源代码版本与包摘要保持可见。
3. 点击“本机按文件演练”。接口立即返回编号，后台读取实际落盘文件并运行。
4. 查看三个节点的结果、测试 SQL 证据、引擎版本和错误；刷新页面可以恢复已保存的包及演练记录。
5. 下载交付包 JSON，或下载单个文件。生成后的文件是只读快照，改代码须重新核验并生成新包。

Data Agent 的已验证代码版本提供“生成该版本交付包”入口，携带对应源运行跳转；当前不是 Agent 自动执行完整上线链路。

## 文件与作用

| 文件 | 作用 | 实际消费者 |
|---|---|---|
| main.sql | 固定源代码版本 | Spark SQL |
| tests.sql | 独立预期结果生成的可执行断言，不由模型自评 | Spark 对真实结果视图执行 |
| schedule.json | 时区、时刻、T+1映射、节点和依赖 | 调度配置解析器与固定链路执行器 |
| deployment.json | 本机适配器、引擎版本、超时和资源边界 | 文件运行器；不创建云资源 |
| calendar.json | 有限范围的虚构证券交易日历 | T+1业务日期解析器 |
| fixtures.json | 当前输入快照与五套独立回归数据 | Spark 输入加载器 |
| validation.json | 源 SQL 的既有验证证据 | 交付包校验器 |
| README.md | 本机执行说明和边界 | 使用者 |
| manifest.json | 源运行/版本、逐文件摘要和大小 | 校验器；解包时由包清单写入 |

下载的单个 JSON 包含 manifest、files、digest，解包后成为上述九个文件。不是浏览器可直接打开的网页。
包不包含 .env、API Key、云端密码或公司数据；这些样例数据均为虚构。

## 当前执行语义

固定链路：执行 SQL → 执行测试 SQL及五场景核验 → 记录证据。
数组顺序可不同，解析器按依赖排序；环、缺依赖、缺节点、未知节点、任意 Shell 指令或未支持的部署参数会被拒绝。

M2a完成时适配器为local-spark-v1/Spark3.5.7；当前本机运行时已升级到3.5.9。校验器继续复验不可变历史包，新生成包绑定实际运行版本；90秒超时、单任务并行度1、768MiB驱动配置保持。
这些是本机运行配置，不是 OS 级沙箱或云端资源隔离证明。
服务内任务共用串行队列；独立 CLI 不共享服务队列，使用时需避免与服务演练同时运行。本轮验收按顺序执行。

日历只覆盖2026-09-10至2026-09-14，样例交易日为10、11、14日。它不是交易所官方日历。
演练时刻2026-09-11 09:00（北京时间）映射到业务日2026-09-10；非交易日不执行，范围外或缺上一个交易日拒绝推断。
映射出的业务日期必须与冻结输入匹配，不能把旧样例数据当作新批次。

这是人工指定历史时刻的文件演练：结果始终包含 published=false、schedulerTriggered=false、clockMode=EXPLICIT_REHEARSAL_TIME。
真正的墙上时钟触发、任务审批、云端发布、回滚与持续监控仍属于 M2b/M2c。

## 完整性、权限与失败

包只允许规定文件名；大小和 SHA-256 均校验。执行必须给出由可信项目记录取得的摘要，不能仅相信包内自报的散列。
散列证明与指定内容一致，不等于生产审批或发布签名。
已失败、过期验证范围或哈希不一致的源运行不能生成包；未知云适配器不会被尝试执行。
拒绝路径穿越、符号链接和覆盖现有解包目录。错误输入不会改动已有代码版本。
公开只读模式不能生成或执行包，跨项目请求仍受统一后端边界限制。
测试 SQL 必须返回唯一的布尔 passed=true；false、字符串true、错误结构、语法/字段错误均不能被算作通过。
如果主 SQL 成功而测试 SQL 报错，保留主 SQL 成功证据，定位到验证阶段，后续证据节点标为阻塞。
取消使用同一后台控制链；服务重启把未完成演练标为中断，不静默重跑。

## CLI 复现

需要本项目源码，以及已安装的Node.js24、Java17、Python/Spark3.5.9。历史3.5.7包仍可在匹配版本中复验；交付包不打包这些运行时。

```bash
node bin/shuzhan-package.mjs unpack bundle.json --output new-delivery-directory --digest <平台记录中的摘要>
node bin/shuzhan-package.mjs plan new-delivery-directory --digest <同一摘要> --scheduled-for 2026-09-11T09:00:00+08:00
node bin/shuzhan-package.mjs run new-delivery-directory --digest <同一摘要> --scheduled-for 2026-09-11T09:00:00+08:00
```

也可使用 npm run v2:package -- 后接相同参数。
run 从目录重新读取并验证文件，不直接复用界面里的 SQL 字符串。结果写入该目录的独立 verification-*.json，不覆盖旧记录。
这是离线包运行器，不是账号管理CLI；V2平台CLI/MCP的完整同源API迁移仍待完成。
