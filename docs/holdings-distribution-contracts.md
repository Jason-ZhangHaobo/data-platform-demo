# 持仓资产类别与行业分布：经典 SQL 验收

输入 `positions` 已含 `asset_class`、`industry`。此前限制来自客户级固定五列输出；本次新增登记契约，不更改旧口径或固定20条完整E2E目录。

| 口径 | 每行粒度 | 占比分母 |
|---|---|---|
| 持仓资产类别分布 | 客户＋交易日＋资产类别 | 该客户当日全部持仓市值 |
| 持仓行业标签分布 | 客户＋交易日＋持仓记录行业标签 | 同上；不穿透基金或其他证券 |

两者均不含现金，不称全资产分布或穿透行业敞口。证券数量在分组内按代码去重；同一持仓编号重复去重、冲突拒绝。空白标签为“未分类”，仅现金客户保留“未持仓”零行，零分母占比为0。仅支持非负市值；金额两位、占比六位小数，范围0—1。各分类四舍五入后合计可能略偏离1。

实现与边界：

- `src/v2/output-contract-metadata.json`保存可供浏览器/模型读取的契约、字段、粒度和约束，`src/v2/output-contracts.json`仅保存独立人工核定的案例预期。Node与Python组合同一登记数据；API、前端及模型不取得独立预期。
- Worker在启动Spark前核对契约、预期、同族回归和持仓输入。校验结果字段、复合键、缺失/范围外分组及金额/数量/占比精度；错误不回显未知标签或客户。保留原客户资产校验逻辑与断言摘要。
- 本机经典开发提供10个新增样例上下文、参考SQL显式载入、实际运行、版本/批次和五场景验证；结果中文标签显示分母。切换上下文保留代码，覆盖未保存内容需确认。
