# 公网域名与 ICP 备案协作清单

当前状态：域名`shuduoai.cn`已购买；按注册时间需等待至少3天后才能提交ICP备案。GitHub `v2-staging`的非秘密目标变量已设置为`https://shuduoai.cn`，但尚未配置DNS、证书或公网部署；备案与HTTPS证据缺失时部署门继续关闭。

## 需要用户亲自完成

1. 确认`shuduoai.cn`的域名持有者信息模板和实名认证状态；不能由Codex代替提交身份证件或手机号。
2. 满足注册后等待期时，在[阿里云 ICP 备案](https://beian.aliyun.com/)提交主体信息和网站备案申请。
3. 完成阿里云要求的短信、人脸或资料核验，并等待审核；审核通过前不要把内地节点入口称为公网可用。

## Codex 自动完成

- 到可提交日期时直接提供[阿里云 ICP 备案入口](https://beian.aliyun.com/)和最少操作说明；
- 读取域名备案/归属/HTTPS脱敏证据并刷新部署门；
- 配置 FC 自定义域名或 CNAME、HTTPS 证书引用和严格 Origin；
- 运行匿名只读、匿名写入401、受邀登录、MySQL/OSS冷启动和 Safari/Chrome 验收；
- 将域名、备案和性能证据写入验收文档，不保存证件或私密资料。

域名未备案前可以继续做私有FC预置、云端数据面和隔离执行验证，但不能配置生产DNS或宣称公网部署完成。
