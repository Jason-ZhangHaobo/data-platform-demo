# 公网域名与 ICP 备案协作清单

当前状态：尚未购买域名、尚未备案；公网部署门保持关闭。

## 需要用户亲自完成

1. 在[阿里云万网域名注册](https://wanwang.aliyun.com/domain)搜索并购买一个项目域名（建议使用与公司内部品牌无关的演示域名）。可用性、首年价和续费价以结算页为准。
2. 创建域名持有者信息模板并完成实名认证。域名注册局审核可能需要等待，不能由 Codex 代替提交身份证件、手机号或支付。
3. 在[阿里云 ICP 备案](https://beian.aliyun.com/)提交主体信息和网站备案申请；内地节点域名解析前必须完成备案。
4. 备案通过后，把最终域名写入 GitHub `v2-staging`：`V2_PUBLIC_URL=https://<你的域名>`、`V2_PUBLIC_ORIGIN=https://<你的域名>`。

## Codex 自动完成

- 读取域名备案/归属/HTTPS 脱敏证据并刷新部署门；
- 配置 FC 自定义域名或 CNAME、HTTPS 证书引用和严格 Origin；
- 运行匿名只读、匿名写入401、受邀登录、MySQL/OSS冷启动和 Safari/Chrome 验收；
- 将域名、备案和性能证据写入验收文档，不保存证件或私密资料。

域名未备案前可以继续做私有 FC 预置和云端数据面验证，但不能宣称公网部署完成。
