# M4e：安全策略、脱敏、权限申请与审计

日期：2026-09-15。当前只使用四个明确标记的本机虚构身份和合成证券数据；`X-Actor-Id`不是认证，未连接公司IAM、真实用户、生产数据或公网会话。

## 产品语义

1. 策略版本保存资产、角色、行范围、字段动作、默认动作与摘要；支持ALL、ADVISOR_CLIENTS和DENY行范围，以及ALLOW、MASK_PARTIAL、MASK_FULL、HASH、DENY字段动作。
2. 没有匹配策略或临时授权即拒绝；未声明字段默认DENY。安全查询先裁剪行再处理列。
3. 财富顾问的ADVISOR_CLIENTS使用内置虚构客户归属，不能读取其他顾问客户。
4. 每次允许或拒绝查询均写审计；审计包含身份、资产、决策、行数、脱敏字段数和策略/授权引用，固定`containsRowData=false`。
5. READ_MASKED/READ_FULL申请先为PENDING，只有DATA_OWNER合成身份可审批；批准授权必须在1—168小时内到期。
6. 安全Agent只读取合成身份、资产字段元数据和策略摘要；模型引用逐项后端验证，应用只创建策略，不查询、审批或扩大授权。
