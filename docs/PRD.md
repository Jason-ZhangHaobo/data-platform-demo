# 数舵 V2 产品需求与边界
版本：3.0 · 更新日期：2026-09-19 · 来源：用户批准的新版计划、UI 补充、完整 E2E/分阶段交付、数据契约、公网部署门、Agent证据旅程、真实交付准备与持久调度边界。
本文件取代旧模拟 MVP 的需求基线；已确认不等于已实现，验收证据见 product-roadmap.md。

## 背景、目标与使用者
用于验证成熟证券数据中台如何融合 Data Agent，并帮助数据中台产品经理理解、讲解和复刻。
用户所在公司的数据中台已建设约8年，经典能力相对成熟，当前建设重点转向智能化与Data Agent。数舵不仅验证自身产品，还要提供可用于公司需求澄清、方案评审和开发落地的参考界面、交互、功能边界、原子API与代码实现。
首要用户为数据开发工程师。优先级：代码编写/调试/核验 → 调度部署上线 → 数据发现。
经典模块可以独立使用，Agent 通过同一 API 工作。统一产品体验、复用成熟引擎。

Data Agent采用Agent-first而不是Module-first：它是默认一级入口和独立全页面工作台，用户描述目标后由Agent选择并编排数据源、同步、开发、治理、服务、报表、发布和运维能力。经典模块保留为专业接管界面，不要求用户先理解产品菜单，也不能把“跳转到模块”当成Agent完成任务。

## 范围与术语
| 领域 | 必须覆盖的经典功能 | Agent 能力 |
|---|---|---|
| 数据源/元数据 | 连接、凭证引用、真实测试、表字段、结构变化 | 配置与错误解释 |
| 同步 | 离线全量/增量、字段映射、CDC、实时、恢复 | 配置生成与诊断 |
| 开发 | SQL/Python、编辑、差异、版本、调试、测试 | 写代码、读报错、修正 |
| 调度发布 | DAG、依赖、交易日历、版本、重跑、回滚 | 生成文件并受控发布 |
| 资产治理 | 目录、字段、血缘、指标、标准、契约 | 语义理解与影响分析 |
| 质量 | 实际规则检测、历史、告警 | 建议规则与修复路径 |
| 安全 | 身份、项目、权限、行列控制、脱敏、审计 | 继承权限 |
| 数据服务 | DAPI/XAPI 开发、测试、发布、授权、监控 | 生成接口与测试 |
| 报表 | 数据集、指标、图表、导出、问数 | 可信查询和解释 |
| 运维 | 日志、状态、资源、成本、恢复 | 基于证据诊断 |

DAPI：单表/参数化 SQL 数据查询 API。XAPI：组合查询或已登记接口的声明式编排，后续扩展受控代码节点。
首期已知表结构、关系和业务口径。小规模虚构证券数据须由真实引擎执行；不使用固定返回值代替计算。
不包含真实交易、公司数据迁出、公司生产接入、未经预算核验的扩容。

| FR-012 | 公网访问 | 公开只读演示；受邀登录后创建；身份由后端核验 |

| FR-016 | M2a版本化交付包 | 已核验SQL、可执行测试SQL、调度/部署文件、日历和输入快照被同一清单及摘要绑定；只接受当前验证范围通过的源版本 |

| FR-018 | 本机受控发布 | 成功按文件演练后，工程师须逐项确认代码、独立断言、DAG/部署文件和“仅本机合成数据”范围，生成摘要与演练编号绑定的审阅记录；审批必须引用该记录且绑定不可变包摘要。本机发布创建独立版本，并由墙上时钟而非手动按钮触发至少两个实际批次 |
| FR-019 | 本机发布后监控与恢复 | 批次保存计划/触发/完成时间、引擎、断言、日志和健康度；失败产生告警，后续成功或回滚有可关联的解除及恢复批次证据 |
| FR-020 | DAPI生命周期 | 从成功的调度发布批次物化独立业务快照；参数、投影、分页、测试、不可变版本、发布、切换及OpenAPI可核对 |
| FR-021 | XAPI生命周期 | 组合2—5个已发布DAPI的精确版本，按声明式字段映射合并；测试、发布、限流、超时和调用日志与DAPI一致 |
| FR-022 | 数据服务应用授权 | 令牌只显示一次且平台仅保存哈希；授权范围、撤销、拒绝、限流和超时均留日志，GUI/API/CLI/MCP共用同一资源 |
| FR-023 | 数据服务Agent | 模型只读取受治理的发布资源摘要并生成方案；后端校验资源ID、版本、字段和限制，人工应用后只创建草稿，不自动测试、发布或发令牌 |
| FR-024 | 数据源与元数据 | 首版LOCAL_CSV限制在合成数据目录；连接测试真实读取文件，元数据记录行数、字段类型、内容/结构摘要及版本间新增/删除/类型变化 |
| FR-025 | 离线全量与增量同步 | 字段映射、主键、水位和源/元数据版本绑定；FULL原子替换，INCREMENTAL_UPSERT区分新增/更新/未变，失败及幂等重放留证 |
| FR-026 | 实时同步与恢复 | 本机事件日志真实逐条处理、事件ID幂等、状态更新、Watermark、Checkpoint、延迟/吞吐；故障后仅在Checkpoint前缀一致时断点恢复并关联告警 |
| FR-027 | 数据资产、血缘、指标与标准 | 从实际源/同步/实时/发布/服务版本自动生成可搜索目录与版本绑定血缘；业务说明版本化；指标与标准必须在实际合成行上执行，Agent只引用已登记资产并披露血缘边界 |
| FR-028 | 数据质量闭环 | 规则与配置版本化，绑定资产证据实际检查；失败保留哈希样本并产生告警，新版本通过后关联恢复；Agent只基于元数据和聚合结果建议规则，不读取业务行或自动执行 |
| FR-029 | 安全、脱敏与权限申请 | 版本化角色/行范围/字段动作策略必须在实际合成行上执行；拒绝失败关闭并审计，临时授权须申请和数据负责人审批；Agent只起草最小权限策略，不读取数据、查询或审批 |
| FR-030 | 数据集、报表与受治理问数 | 从可报表资产实际物化独立不可变快照，报表版本固定快照并执行KPI/柱状/饼图聚合；导出仅含聚合结果且标识维度默认脱敏；Agent只基于字段与快照摘要起草，不读取行或自动运行 |
| FR-031 | 跨模块运维与事故诊断 | 归一开发/同步/实时/发布/质量/服务/报表失败和恢复证据；事故确认不等于解决，解除必须使用同资源且晚于失败的成功运行；运维摘要默认禁止外发，Agent诊断需单独明确授权且不可执行 |
| FR-032 | 公网邀请认证与项目权限 | 公开内容匿名只读；邀请码一次性且限时，密码只存强哈希；受邀会话使用Secure/HttpOnly/SameSite Cookie、CSRF和后端角色授权，模型密钥不得经公网页面读写 |
| FR-033 | 云端冷启动恢复 | 平台元数据写入独立MySQL，落地行、实时状态/Checkpoint、DAPI业务快照和报表快照写入私有OSS；成功响应等待持久化，函数冷启动后恢复同一版本和实际数据；并发冲突失败关闭而非静默覆盖 |
| FR-034 | 公网隔离Spark执行 | 控制面只连接健康检查通过的独立Worker；请求绑定项目、时间戳、随机数和正文签名，限制大小/超时并防重放；Worker只接受白名单证券上下文，成功结果仍须包含独立断言，真实云资源与网络隔离另行验收 |
| FR-035 | 不可变版本产物 | SQL、测试、DAG、日历、输入和部署清单以交付摘要作为私有OSS对象键，首次仅创建、重复内容可幂等、同摘要不同内容失败；审批、演练和发布前重新读取并校验对象，元数据记录不得替代实际产物 |
| FR-036 | 公网账号密码安全 | 管理员自选密码不得进入仓库、对话或长期云环境变量；本机安全输入只生成参数固定的scrypt哈希，GitHub/FC只保存哈希，云入口检测到明文引导变量必须拒绝启动；登录后改密验证当前密码并撤销全部旧会话 |
| FR-037 | 月度预算硬门 | 按月汇总模型输入/输出Token费用估算、远程Spark次数与实际秒数；启动前预留最坏额度，超过资源阈值或已核验账号支出达到200元时返回429且不创建任务；未连接账单时必须明确不能证明全站费用 |
| FR-038 | 数据契约与变更影响 | 从当前资产证据创建不可变契约版本；支持BACKWARD/FULL/NONE兼容策略、结构差异、下游影响和破坏性变更确认；检查必须读取实际元数据及可用实际行，执行行通过率与新鲜度SLO，证据不足标PARTIAL而非冒充完整通过；失败告警须关联后续通过检查恢复 |
| FR-039 | 公网部署证据与保密门 | 手动部署只能引用专用函数、当月且24小时内的脱敏云审计、实时账单、同VPC/单并发/最小角色、私有OSS、HTTPS及备案/域名归属证据；函数与域名哈希必须匹配目标。未验收或任一门失败不得部署；云ID只在受保护环境配置，不在工作流硬编码；更新函数环境使用白名单新值，不继承旧秘密 |
| FR-040 | Agent七阶段证据旅程 | 对同一代码Agent任务只读串联需求、SQL版本、Spark独立断言、调度文件、部署清单与文件演练、摘要审批/计时发布、上线后监控；每阶段引用实际资源ID/摘要并标明Agent/工程师/调度器责任。只完成代码或人工接管后的步骤不得计作Agent自主E2E；历史发布和公网未部署明确标识，不返回业务行或原始报错 |
| FR-041 | Agent受控交付准备 | 已通过真实模型和Spark五场景断言的代码委托可在后台自动生成不可变调度/部署包，并按文件再次用相同Spark版本执行主SQL、测试SQL和独立回归；任务可查询/取消/中断恢复，假引擎或假回执失败关闭。已审批的旧包不得复用为本次准备，以免继承旧批准。成功后停在工程师审阅，不自动审批、发布、下发密钥或公网部署；GUI/API/CLI/MCP共用同一资源 |
| FR-042 | 统一 Data Agent 入口 | 用户可用一个入口提交跨模块任务意图；模型只能从白名单模块推荐一个起点及最多三步不重复的后续专业模块链路，返回摘要、理由、置信度和风险等级。用户可把某一步交接到已适配专业Agent输入框，平台记录可审计交接但不会自动提交下游方案。非管理员只读自己的意图和交接历史，管理员可审计项目全量；响应不返回提交者内部标识或原始任务描述。新任务只持久化描述哈希与长度，明显的密钥、密码、令牌、连接串和私钥输入拒绝。路由不接收业务行、凭证或内部地址，且不直接创建同步、查询、审批、发布、令牌或权限变更；专业模块仍通过自身API、角色和审阅关口执行 |
| FR-043 | 公网部署前置看板 | 管理员可读取单个脱敏云审计报告的就绪状态、检查项、失败项和账单摘要；浏览器不得获得函数名、VPC、Bucket、连接地址、账号、密钥或审计原文。未满足专用函数、同VPC、备案/HTTPS和预算门时，部署保持阻断 |
| FR-044 | 服务端 MySQL 数据源 | 数据源可登记服务端环境已配置的合成MySQL白名单表；浏览器/API/CLI/MCP不得提交或返回连接地址、账号、密码、Token或连接串。首期只允许连接探测和字段/行数元数据采集，MySQL同步执行在真实数据面验收前保持关闭 |
| FR-045 | Agent 路由轨迹 | 模型路由和用户显式专业交接必须保存不含原文/业务数据的顺序轨迹；轨迹可按意图由任务所有者或管理员读取，并标明模型、步数、目标与NO_EXECUTION，不得把轨迹当作下游任务已执行 |
| FR-046 | 受保护部署配置 | 部署工作流支持逐项GitHub Environment Secrets，也支持名为`JASONSECRETS`的白名单JSON/单行KEY=VALUE包；逐项值优先，展开只写临时Runner环境，任何缺失、未知键或多行值均失败关闭且不得回显 |
| FR-047 | 云端持久调度 | 云端发布不得依赖FC实例内`setTimeout`；外部调度tick使用独立HMAC域、时间戳、Nonce和正文签名，Nonce在元数据库持久化防重放。领取批次先持久化运行租约再执行，实例中断后仅过期租约可重新领取；本机ACTIVE_LOCAL批次不得被云tick执行。驱动未启用、密钥缺失或真实云运行未验收时保持关闭且不得宣称调度上线 |
| FR-048 | 独立Data Agent工作台 | Data Agent为默认一级入口和独立全页面体验，具备新任务、历史会话、中央对话、上下文、跨域计划、工具活动、产物、审批模式和证据轨迹；不得依赖任一经典模块页面才能理解或推进任务。模块工作台仅作为可选精细编辑/人工接管入口 |
| FR-049 | 会话内专业Agent编排 | 同一会话可调用数据源/离线同步、实时、开发、资产、质量、安全、DAPI/XAPI、报表、调度准备和运维专业Agent；调用复用原模块API、身份、预算与审计。PLAN_ONLY只能规划，REQUEST_APPROVAL由用户逐步触发；草稿应用、运行、发布、授权和高成本操作按风险独立确认 |
| FR-050 | Agent能力真实性 | 每一步必须区分计划、专业Agent任务、草稿已写入、真实运行、审阅批准、发布和监控，不得以路由、handoff、按钮或聊天文案冒充执行。会话任务刷新后可恢复非敏感状态和证据；原始意图仍只保存哈希与长度 |
| FR-051 | 私有FC冷启动烟测 | 域名备案前允许通过FC `InvokeFunction`对预置控制面执行只读健康事件，仅返回MySQL元数据与OSS状态的驱动/健康布尔，不返回项目、资源ID、地址、账号或业务数据。入口必须同时要求非本机、预置模式和显式开关；公开更新移除开关。部署角色不因此增加Invoke权限，临时调用由已登录Cloud Shell管理员完成并单独记录证据 |
| FR-052 | 受控服务端MySQL离线同步 | SERVER_MYSQL只有在服务端凭证完整、表名白名单和同步开关同时成立时才可创建任务。FULL读取有界快照并原子替换；INCREMENTAL_UPSERT首版读取有界全表快照后按主键做差异合并，必须明确不是CDC或源端增量。运行前重扫Schema并绑定元数据版本；限制5000行、4MiB和15秒查询，拒绝二进制/对象字段。API、GUI、CLI、MCP不接收或返回连接信息、业务行或原始数据库错误 |
| FR-053 | Data Agent步骤批准与绑定 | REQUEST_APPROVAL模式下，每个专业步骤在创建或关联专业Agent任务前必须生成持久批准记录，绑定意图、目标模块、目标摘要哈希和风险；PLAN_ONLY拒绝批准及已执行任务关联。批准可幂等恢复，专业任务绑定后状态转为BOUND并写顺序轨迹；刷新后GUI/API/CLI/MCP读取同一批准。批准者内部标识不出响应，批准不等于草稿应用、运行、发布或授权 |
| FR-054 | Data Agent统一任务图 | 按父意图只读汇总计划顺序、风险、目标哈希、批准、交接、专业任务类型/ID/状态及完成数，GUI/API/CLI/MCP共用同一图。任务图不返回原始需求、业务行或批准者标识，不创建第二套执行状态；没有专业任务证据的步骤固定为NO_SPECIALIST_EXECUTION，任何本机图都保持agentIndependentE2E/publicDeployed=false |
| FR-055 | Data Agent停止与子任务边界 | 用户可停止QUEUED/RUNNING或尚未绑定子任务的SUCCEEDED父意图，撤销未消费批准并写取消轨迹；取消后不能再批准或执行专业步骤。若已绑定专业子任务，父取消必须拒绝并提示分别检查/取消子任务，不能以父状态伪造子任务停止。GUI/API/CLI/MCP共享同一操作并要求明确确认 |
| FR-056 | Data Agent人工接管审计 | 用户从独立Agent打开经典专业工作台前，平台必须幂等记录目标模块和目标哈希的NO_EXECUTION交接，再执行页面跳转；重复打开不新增记录或轨迹。该记录只证明人工接管入口已打开，不创建专业Agent任务、草稿、运行、批准或发布 |
| FR-057 | 专业Agent取消竞态一致性 | 集成、实时、开发、资产、质量、安全、数据服务、报表和运维专业Agent在模型返回后、写入方案/代码/诊断前必须重读持久任务状态；若已CANCELLED立即结束。即使模型忽略AbortSignal，取消后也不得生成方案、代码版本、Spark运行或成功状态 |
| FR-058 | 统一专业子任务取消 | 父意图所有者或ADMIN可按推荐模块取消已绑定且仍为QUEUED/RUNNING的专业子任务，保留父意图、批准、交接和取消轨迹；CANCELLED重复请求幂等。SUCCEEDED/APPLIED/FAILED等终态拒绝取消，未绑定任务返回404。GUI/API/CLI/MCP共享该操作并要求明确确认 |

## 数据、接口与异常
公共资源：Project、Context、CodeRevision、AgentTask、ExecutionRun、ReleaseBundle、DAPI、XAPI、ServiceVersion、ServiceApplication、ServiceCall、DataContract、ContractVersion、ContractAssessment、ContractCheck。
新版使用 /api/v2；旧 /api 明确为 legacy demo。平台元数据与业务数据分库，产物按项目和版本隔离。
公网小规模试点允许以内存SQLite作为单实例查询索引，但其业务状态必须由私有OSS快照恢复；MySQL与OSS分别使用条件更新，函数并发固定为1。该低成本两存储边界不等于多实例生产架构，扩大并发前须迁移到事务性业务库或实现跨存储提交协议。
未配置模型/Spark/数据库应返回明确配置状态；绝不回退到固定模拟成功结果。
本机/仓库中的云端预检只决定是否允许进入部署；真正公开后还须验证HTTPS、受邀登录、业务行冷启动恢复和隔离执行，预检通过不得冒充公网可用。
公开模式不执行任意代码；本地开发会话仅绑定回环地址，不可当作公网身份认证。

## 统一验收与交付
至少 20 个完整证券开发交付场景；Agent E2E 完成率目标 ≥85%。其含义是以下完整链路，而不是 SQL 跑通率：

理解需求 → 写代码 → 调试与结果验证 → 生成调度文件 → 生成部署文件 → 真实上线 → 上线后运维监控。

| 环节 | 必须留下的实际证据 | 不构成完成的情况 |
|---|---|---|
| 理解需求 | 需求/业务口径记录、输入表字段、输出契约、执行时间和目标环境；关键歧义已澄清 | 只复述提示词，遗漏现金口径、范围或调度要求 |
| 写代码 | 引用真实上下文的不可变代码版本和差异 | 固定模板冒充模型生成，代码未落盘 |
| 调试 | 真实引擎运行批次、报错/修正记录、独立业务断言；正常用例无须刻意制造错误 | 只做语法检查、返回 200、固定结果或模型自评 |
| 调度文件 | 与代码版本绑定的 DAG、依赖、日历、参数、重试/超时；调度器能解析并实际触发 | 仅展示 YAML/JSON 文本 |
| 部署文件 | 可执行部署清单、运行时/依赖、目标环境、凭证引用与资源约束，校验通过 | 配置不完整或包含明文密钥 |
| 上线 | 审阅批准绑定产物哈希，真实发布记录、部署版本与调度运行一致，结果核验通过 | 状态改为“已发布”，没有真正部署和运行 |
| 上线后监控 | 真实批次日志/状态、时效与失败信号；监控规则确已生效；故障场景可关联告警、诊断和恢复记录 | 假监控数据，或运行刚结束就默认上线后健康 |

全链路成功数 / 冻结评测集中的有效完整任务数为最终口径；首批至少 20 个场景，20 个时至少 17 个完整成功。
必须披露样本覆盖率、未执行、阻塞、取消和失败，不能挑选成功样本或删除失败样本提高比例。评测未跑完只报告进度，不宣称最终达标。
同一任务内部的有限修正/重试不新增分母。预先约定的业务澄清、审阅和上线批准允许人工参与，需记录等待时间；人工代写/代调关键产物后的完成另记“人工救援”，不计 Agent 独立闭环成功。
权限拒绝、危险操作拦截、回滚等安全用例单独统计，不能用“成功拒绝”充当业务链路完成来抬高 85%。
新代码、新调度或部署清单改变后，原批准/旧验证不能直接复用；审阅、发布、批次和监控必须关联到同一目标版本。
交付准备阶段由Agent编排固定规范与真实执行，不声称模型生成了调度文件，也不计“审批→发布→监控”的Agent自主完成。对新包的监控必须按该包实际发布版本显示，不能借用其他健康版本的成功批次。
本机演练、测试环境与最终公网验收分开记，不能用本机通过替代公网产品可用。

允许分阶段实现：M1 代码开发 → M2a 调度与部署文件 → M2b 真实上线 → M2c 上线后监控闭环。
各阶段单独设置完成门槛，完整 ≥85% 指标在链路连通后评测；不得把 M1 的模型写 SQL 成功率重命名为完整 E2E。
实施默认：先做标杆任务的最小监控闭环，至少观察两个实际调度批次；含故障的用例还需告警与恢复证据。测试环境可使用短周期，但必须记录与生产 T+1 调度的区别，不能用手动触发伪装定时运行。观测窗口与 SLA 在 M2 实测后固化。

本机 M2b/M2c 使用短周期墙上时钟验证调度器，业务参数仍来自有限的虚构交易日历；`published=true` 只表示本机版本已激活，必须同时返回 `publicDeployed=false`。本机通过不得改写为公网或生产上线。

2026-09-15冻结范围已完成20条本机完整链路评测：20/20通过、40个实际调度Spark批次，均先在当前Spark3.5.9重跑原冻结模型SQL；七阶段包含独立审阅记录，且有3次阻塞、1次取消和4次救援。该结果满足当前`LOCAL_ACTUAL`范围的≥85%门槛，但评测审阅是预声明的本机合成执行者确认，不是受邀用户生产批准；20条仍由4类客户资产开发意图×5套输入构成，不代表不同输出契约、全部经典模块或公网E2E已经达到同一成功率。

M4接入首版只把仓库内虚构CSV作为真实可重复数据源，不声称已接通用户文件、公司系统或云数据库。落地区使用独立SQLite；平台元数据只保存配置、摘要和运行证据。
实时首版使用`local-event-log-v1`有限JSONL重放验证语义，必须同时声明`kafkaConnected=false`和`flinkConnected=false`；不能把本机事件处理冒充真实Kafka/Flink生产链路。
资产首版血缘来自同步映射、实时任务、发布批次和DAPI/XAPI版本绑定；只有同步映射提供字段映射。Spark SQL字段级表达式解析尚未实现时必须显式披露，不能用表级关系冒充完整字段血缘。指标首版仅对有实际本机行数据的落地表和实时状态表执行。
数据契约V1必须来自当前资产字段和证据摘要，不允许手填一个与资产无关的“已通过”结构。兼容评估只产生待审方案，不自动改当前版本；BACKWARD下新增必填字段、删除字段、修改类型或把非空改为可空均视为破坏性。实际检查同时记录结构、行通过率和新鲜度；缺少行或时间证据时返回PARTIAL，不能显示PASSED。
质量首版支持非空、唯一、数值范围、允许值和时效规则；每次运行绑定规则版本、配置摘要与资产证据摘要。失败行不返回原值，只保留行摘要；规则配置更新必须创建新版本，不能覆盖导致告警的历史配置。
安全首版使用明确标记的本机合成身份验证行列策略语义，`X-Actor-Id`不能被称为公网认证。默认未授权即拒绝；策略未声明字段默认DENY。权限申请、审批、临时授权、允许/拒绝查询均审计且不保存业务行。
报表数据集创建与快照刷新分开：草稿不复制数据，刷新才实际物化并保存行数/内容摘要。报表版本固定快照，后续数据集刷新不改写旧报表证据。客户/持仓标识作为维度输出时默认脱敏，CSV不得导出业务明细行。
运维事故由实际失败运行幂等生成，并关联Checkpoint恢复、规则版本恢复或发布回滚。事故源/恢复证据对外只返回状态、错误码和执行摘要，不返回业务行。即使先别名化，运维域和聚合状态仍属于需单独授权的外发上下文，默认禁止调用外部模型。
公网角色首版为ADMIN、ENGINEER、PRODUCT_MANAGER、VIEWER；权限由后端按API资源判断，按钮禁用只用于体验。匿名写入401、缺CSRF 403、越权403。`V2_ALLOW_INSECURE_PUBLIC_COOKIES`只允许回环预览，非回环启动必须失败。

覆盖重复、空值、精度、口径变更、修复、权限、超时、幂等与恢复。
国内两类网络、Safari/Chrome 首屏可操作目标 ≤3秒；分别记录冷启动和常规响应。
文档、代码、接口说明与验收记录同步；缺少凭证/资源的检查标为待验证，不填通过。
