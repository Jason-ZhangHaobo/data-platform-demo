# 公网邀请认证与项目权限

更新：2026-10-25。既有回环public-preview验收与本轮持久认证回归分别记录；尚未在正式HTTPS入口完成受邀用户链路验收。

## 用户体验

- 未登录用户可公开浏览全部虚构证券演示，所有写按钮禁用。
- 已有成员使用邮箱和密码登录；首次用户使用一次性邀请码、显示名称和自设强密码兑换。
- 会话建立后，顶部显示“受邀会话”和用户；侧栏显示项目角色。退出后立即退回公开只读。
- ADMIN在平台设置创建ENGINEER、PRODUCT_MANAGER或VIEWER邀请；邀请码只显示一次并提示立即复制。
- 公网模式不显示模型Key输入框，任何角色都不能从网页替换服务密钥。

## 服务端约束

1. 邀请码使用24字节随机值，只存SHA-256，7天到期，成功兑换后状态变REDEEMED。
2. 密码12—128位、四类字符至少三类；以scrypt(N=16384,r=8,p=1,64字节)和随机16字节盐保存。
3. 会话令牌32字节随机值，只存SHA-256，8小时到期；同一用户新登录撤销旧活动会话。
4. Cookie为HttpOnly、SameSite=Strict、Secure(公网)；CSRF使用单独同站Cookie和服务端哈希比较。
5. 匿名写401；缺CSRF、跨项目、错误Origin或角色越权403。登录失败使用统一消息。认证尝试以服务端身份独立限流，固定15分钟窗口最多5次；客户端IP、转发头或邮箱大小写不能重置账号额度。
6. 回环预览可显式设置`V2_ALLOW_INSECURE_PUBLIC_COOKIES=true`，但非回环主机使用该设置会拒绝启动。
7. 已登录用户修改密码必须再次验证当前密码；成功后撤销该用户全部旧会话、签发新会话并审计。新密码不得与旧密码相同。

## 角色

| 角色 | 首期写能力 |
|---|---|
| ADMIN | 全部资源、邀请、安全策略与设置（公网模型Key除外） |
| ENGINEER | 开发、交付、接入、实时、资产、质量、服务、报表、运维、权限申请 |
| PRODUCT_MANAGER | 资产、数据服务、报表与权限申请 |
| VIEWER | 公开只读，无写能力 |

权限由后端根据API路径执行；前端按钮禁用不是安全边界。

## 管理员首次引导

公网函数不接收`V2_BOOTSTRAP_ADMIN_PASSWORD`明文变量；若发现该变量会在监听端口前拒绝启动。管理员密码由本人在本机终端无回显输入，只把scrypt哈希保存为GitHub Environment秘密`V2_BOOTSTRAP_ADMIN_PASSWORD_HASH`和FC环境配置。仓库、对话、命令参数和部署日志均不需要明文。

本机生成方式（密码不写入命令历史）：

```bash
read -r -s -p "请输入公网管理员密码: " task_admin_password
printf '%s\n' "$task_admin_password" | npm run --silent v2:admin-hash
unset task_admin_password
```

输出哈希只用于首次创建管理员。MySQL中已存在同邮箱用户后，冷启动不会覆盖密码；后续正式版本需增加登录后的改密/轮换功能，再移除引导哈希。

## 验收与剩余风险

### 持久认证保护（2026-10-25）

- 登录和邀请码兑换先创建`auth_attempt`预留并持久提交，再校验密码或生成密码哈希；共享快照CAS失败或数据库不可用时不执行验密，不返回登录Cookie。会话持久化失败同样不能返回认证成功。
- 现有账号、已登记邀请码各有独立计数，不使用FC代理地址作为所有用户的共同额度。未登记的邮箱/邀请码各使用128个固定槽，防止随机输入无限增加元数据；未知身份之间可能共用槽，但不会挤占已登记身份额度。
- 固定窗口内失败不延长截止时间。成功仅在没有更新的在途预留时清空自身计数；未知结果保守保留预留，实例重建后不会清零。不保存明文邮箱、IP、密码或邀请码到限流记录。
- HTTP只调用异步`authenticate`，预留和会话分别等待持久化；同步`login`/`redeemInvitation`仅用于本机内部调用与测试，不是云端认证入口。
- 测试入口：`test/v2/auth-durable-limits.test.mjs`。覆盖副本重建、身份隔离、预留失败不验密、两个副本竞争最后额度、未知输入存储上限、邀请保护、真实回环HTTP退出恢复及会话保存失败不发Cookie。内存CAS替身同时改为原子比较，避免测试隐藏并发冲突。
- 本轮定向15项通过；完整CI700项（699通过、0失败、1既有跳过），类型、构建及入口体积门通过。真实HTTP指本机回环，云持久层为CAS替身，不冒充云端MySQL、多实例HA或正式HTTPS验收。

这不是边缘防刷或全站费用硬上限。仍保持现有单实例、单请求并发的试点边界；不能据此提高FC容量或并发。正式开放前须独立验收云持久化、真实浏览器与异常请求边界；按量资源的账单延迟和匿名流量风险需单独控制。

同轮只读开放准备见[受邀工作台合同](invited-workbench-acceptance.md#先只读验收再开放计算)：最终合并回归704项（703通过、0失败、1既有跳过），33项认证/隔离/私有通道定向通过；本机内置浏览器用虚构账号验证登录、刷新及退出，查看只读横幅和禁用按钮。没有使用实际用户凭证，没有连接云持久层，没有模型/Spark执行，不代表正式域名已开放。

### 历史预览验收与未完成项

API和浏览器预览均已覆盖管理员登录/邀请、一次性兑换、工程师权限、退出、CSRF和公网模型Key拒绝；后续新增哈希引导及改密/旧会话撤销，当前全量CI为170/170。

改密界面已在临时回环public-preview中实测：确认值不一致时保留输入并提示；成功后新会话继续可用；退出后旧密码失败、新密码登录成功。临时服务关闭后数据销毁，不算HTTPS公网验收。

仍需在真实HTTPS域名、云端持久元数据库和至少两个独立浏览器会话中验证Cookie、并发、重启恢复、邀请竞争兑换；忘记密码恢复、邮件发送、账号禁用和审计留存仍有产品缺口。持久认证保护已在本机实现并回归，但尚未部署/云验收，不能沿用旧内存Map作为公网保护。
