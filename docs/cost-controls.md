# 费用控制与停损手册

更新日期：2026-09-15。**理想月费用不超过50元，绝对硬上限为200元/月。** 试用、代金券或免费额度到期后不假设继续免费，所有判断以账号账单为准。

## 当前状态

- 本机开发不新增云计算费用；模型已有少量真实调用，估算见[v2-budget.md](v2-budget.md)。
- 已知存在RDS Serverless试用、FC和OSS，但当前规格、优惠截止、存储、请求及公网流量账单尚未完成账号内只读核验。
- V2部署工作流只允许独立staging函数，最小实例数必须为0、实例并发为1；当前不会自动触发。
- 预算告警只能通知，不等于自动关停；需要产品级配额、部署门和人工停损组合。
- 应用内硬门已实现：模型默认50元/月，远程Spark默认200次且累计3600秒；启动前预留一次最坏额度，超限返回429且不创建Agent任务/远程运行。GUI/API/CLI/MCP读取同一状态。
- `V2_ACCOUNT_MONTHLY_SPEND_CNY`只有在部署前从账号账单核验并注入时才参与200元硬停；为空时固定显示`NOT_CONNECTED`。这避免用应用估算冒充完整账单，但仍需自动账单连接器。

## 预算分层

| 月度累计/预测 | 动作 |
|---:|---|
| 10元 | 提醒：核对RDS、模型、FC调用和公网流量明细 |
| 50元 | 警戒：暂停非必要Agent评测与性能压测，优先使用本机 |
| 100元 | 高风险：停用公网写入和云Spark执行，仅保留只读演示 |
| 160元 | 紧急：关闭HTTP触发器/异步任务，检查异常调用与未暂停资源 |
| 200元 | 硬停止：不再发起任何收费调用；取得明确新预算前不得恢复 |

预测支出达到对应阈值时执行同级动作，不等待实际出账。阈值、通知人、时间和处置结果写入运维审计。

## 资源门禁

- FC不创建最低实例、预留实例、常驻资源池或包年包月CU；控制面512MB/0.25 vCPU，Spark执行单元按需启动且串行。
- 不因构建方便自动创建NAS、ACR、SLS或第二套RDS；若技术方案必须新增资源，先更新总成本估算并取得明确批准。
- RDS Serverless保留自动暂停和最低0.5 RCU；自动暂停不消除存储、备份或公网等其他费用。
- OSS只保存小型状态/版本包，设置合理生命周期；日志和快照不得无限增长。
- 模型限制每任务Token、最多三次修复、请求超时和月度任务数；不得用无上限重试提高完成率。
- 模型费用按实际usage估算；缺usage按32,000 Token和对应高输出单价保守计入，未知模型按最高配置档计入，避免缺字段绕过预算。
- 公网入口有邀请认证、应用限流和总调用配额；异常流量先关闭触发器，再调查。

## 每次部署前后

部署前：

1. 查询当月账单、昨日账单、资源实例和优惠到期日；记录截图之外的结构化结果。
2. 计算固定成本与本次最坏增量，确认仍低于200元。
3. 检查FC最小实例0、目标函数独立、VPC/角色/OSS/RDS最小权限、代码包无秘密。
4. 先跑全量CI和匿名拒写、安全Cookie、冷启动恢复门禁。

部署后：

1. 验证调用量、错误率、冷/热延迟、RDS连接、OSS请求与模型Token。
2. 当日和次日复查账单，避免出账延迟导致误判。
3. 演示结束停用写入/执行触发路径；只读入口是否保留按当月预算决定。

## 可恢复停用顺序

1. 暂停Agent和Spark执行；保留版本与运行证据。
2. 暂停受邀写入，只保留公开只读。
3. 禁用FC HTTP触发器或函数调用；不要先删除状态。
4. 导出/校验MySQL元数据和OSS状态快照，记录恢复步骤。
5. 删除函数、数据库、Bucket或域名绑定属于破坏性操作，必须逐项取得当时的明确批准；本手册不授权自动删除。

## 试用到期前

至少提前14天核验RDS试用截止、续费方式和按量价格。若续费会使固定费用超过预算：先导出平台元数据和业务样例、停止公网写入和执行，再选择更小规格/其他存储或申请新预算。不能依赖“到期自动释放”替代备份，也不能承诺由系统自动取消尚未确认的订单。
