# 费用控制与清理手册

## 当前上限

- 期望费用：0 元（使用免费试用额度）。
- 月度警戒线：10 元。
- 用户授权的绝对预算：50 元/月。

阿里云预算和成本告警只会通知，不会自动停止资源。因此必须同时使用资源配置和人工清理控制费用。

## 已确认的通知

阿里云账号联系人当前已启用以下渠道：站内信、短信、邮件。

- 账户余额不足与资金消息。
- 产品欠费、停服和释放通知。
- 产品到期通知。
- 账单类消息。

## 上线时必须检查

- FC 最小实例数为 `0`。
- 不创建预留实例或包年包月 CU。
- 不自动创建 NAS、RDS、SLS 或 ACR。
- OSS 只保存小型 JSON 状态文件。
- staging 和 production 之外不创建第三套环境。

## 预算规则

预算管理可用后创建月度费用预算 `data-platform-demo-monthly`：

1. 实际支出达到 1 元：提醒检查是否仍在免费额度内。
2. 实际支出达到 5 元：警告并检查函数调用和 OSS 请求。
3. 实际支出达到 10 元：立即停止演示并评估删除资源。
4. 预测支出达到 10 元：提前警告。
5. 实际支出达到 50 元：严重告警；该阈值不是自动停机开关。

## 试用结束前

1. 从 OSS 下载 staging 和 production 的状态 JSON。
2. 删除两个 HTTP 触发器和两个函数。
3. 确认没有预留实例、NAS、SLS、ACR 或其他关联资源。
4. 删除两个 OSS Bucket。
5. 第二天和第四天复查账单，考虑出账延迟。
