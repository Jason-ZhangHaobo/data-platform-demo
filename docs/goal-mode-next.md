## 总目标与边界

继续现有数舵项目，交付国内公网HTTPS实际可用、智能化、功能全面、易用且有审美的数据中台。Data Agent是独立任务工作台；经典模块保留独立操作和人工接管。GUI/API/CLI/MCP共享身份、权限、资源、版本和结果。面向已建设约8年的证券公司中台，形成可借鉴的设计、代码、接口和复刻材料。

仅使用虚构中国证券数据，覆盖经纪财富管理和资产管理/基金。禁止公司资料、内部地址、真实业务数据及凭证进入公开仓库、报告或模型。参考DataWorks、Databricks、Snowflake、Fabric等产品，以真实任务效果判断差距。

月运行费用尽量≤¥50、上限¥200；核算既有资源、试用到期、模型、存储、计算、流量和域名。预算告警不等于账号硬封顶。

- 备案：个人主体、北京方向已确认。Codex核验域名实名、备案资源和订单，准备真实的网站名称/内容/技术说明并辅助非敏感表单；用户在官方页面完成证件、人脸、短信和真实性确认。新购资源须先明确商品、金额和期限。详见domain-registration-checklist.md。
- 经典模块：逐项补齐数据源/元数据、离线全量/增量/CDC、实时同步、SQL/Python/实时开发、调度发布、目录/字段血缘、指标/标准/契约、质量、安全/脱敏、DAPI/XAPI、报表问数、运维和成本。每项列明现状、差距、手动流程、API/CLI/MCP、Agent和真实证据。
- CSV/JSONL回放不计CDC/Kafka/Flink，表级血缘不计字段级SQL血缘，模拟适配器/菜单不计功能完成。预算不足或范围变化提出具体取舍，不静默删减目标。
- 体验：统一导航、任务/产物组织、布局、字体、间距、错误恢复、键盘操作和响应式；失败保留输入、长任务及时反馈、刷新可恢复。按实际用户旅程验收。

## 公网验收与交付

1. 备案完成后配置DNS、FC域名、HTTPS证书/续期和严格Origin；匿名演示只读、受邀用户按项目权限使用。
2. Safari/Chrome及国内两类网络实测首屏可操作目标≤3秒，冷/热启动分开记录。条件缺失保持待验收。
3. 预先冻结至少20个不同证券开发任务，覆盖完整七环节和实际调度批次；Agent独立成功≥85%（至少17/20）。约定澄清/审阅可参与，人工代写/代调/关键救援单列；保留失败/取消/阻塞/未执行，安全拒绝另算。
4. 比较手工/Agent时间、操作、返工和成本；更新需求、决策、路线、架构、接口、验收、费用与恢复手册。
5. 交付公网地址、邀请说明和公司适配/复刻手册。最终范围完成或用户明确要求时生成全流程PPT，含总路线、用户/Codex双路线、里程碑、产物及作用。

## 高效执行规则

- 用户计划使用Astra梳理、Sol执行。切换模型不改变目标、权限和验收标准；每次先读本清单的最近证据与唯一下一步，只跑能解决具体风险的验证。不可承诺模型切换会自动保证效果，以独立断言、完整CI、云回读、真实运行及公网验收证明质量。
- 继承已授权的常规实现、修复、测试、推送、合并和部署；新云权限、新购付费资源、不可逆删除和范围调整需具体确认。
- 优先CLI/API。登录态不代表新权限审批；不反复折腾Safari焦点，不把静止页面当活着的Cloud Shell会话。
- 根据失败证据修复并针对性验证；无新证据/改动不重复部署或全套测试。云等待时推进独立任务。
- 需要用户操作直接给准确界面或链接。三项配置已完成；密码、证件无需发到聊天。
- 文档、代码、已部署、已验收区分记录；避免“全完成只差公网”的笼统说法。单个部署/备案阻塞不代表所有开发都无法推进。
- 全部约定范围、公网验收、成本恢复、复刻材料与最终PPT完成后才关闭总目标。
