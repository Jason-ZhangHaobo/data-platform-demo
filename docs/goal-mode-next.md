## 当前唯一主线

当前代码增量聚焦DAPI/XAPI消费原已核验发布结果：默认关闭的私有服务通道、来源/版本与快照绑定、独立应用授权、限流和调用日志；在Agent独立界面与经典模块共用同一API。代码与合成本机回归不能替代私有云验收，实际部署/消费/清理证据仍仅看受保护续接文件。正常发布链路已验收的环境不应重复生成模型任务或计算批次；下一轮复用其结果进入服务消费。

补齐独立 Agent 工作台中的 **核验 → 交付文件 → 审阅发布 → 调度批次 → 监控与恢复**。先复用已通过核验的原代码版本与不可变交付包，不重复生成模型任务或新建底层资源。

通用实现已包含：

- 逐项结果核验报告，以及 SQL、测试 SQL、调度 DAG、部署清单、日历、冻结虚构证券数据与验证契约的版本化交付包。
- 持久化 Spark 文件演练、原提交编号恢复、代码变更使旧核验/批准失效，以及取消后迟到结果不复活任务。
- 默认关闭的私有云发布：审阅绑定准确包摘要和成功演练，规划两个冻结样例测试批次；发布创建本身不提交计算。
- 签名、限时且绑定发布编号及精确触发器名的云端事件，最多每事件提交一个新批次；重复事件不创建第二份工作。
- 运行批次、失败告警、后续成功关联恢复、停止后续批次、同页读取及导出。GUI、API、CLI、MCP 共用发布记录。

测试使用合成模型、虚构证券数据和合成队列；不能计作真实模型、Spark 云端执行或完整 E2E 验收。真实云端触发器与批次是否部署、验收，仅以受保护运行记录为准。版本回滚、永久调度、DAPI/XAPI 消费及完整评测仍须继续交付。

## 唯一下一步与通过门槛

1. 完成定向回归与完整 `npm run ci`，保留通用代码变更；公开内容不得含实际云标识、账单、日志或派生运行指标。
2. 复用现有私有控制面、Worker、MySQL 与 OSS；只更新核验后的不可变代码包，保持原网络、角色与容量边界。
3. 新触发器必须按精确函数、事件数、两个冻结样例批次、签名时限、月预算和清理范围取得具体授权，不能从“继续”推断扩权或永久调度授权。
4. 真实验收必须证明：审阅版本被调度执行、结果通过独立断言、同一包与批次对应、刷新恢复、失败/取消边界；配置回读成功不等于业务成功。
5. 测试后清理临时触发器，核实无永久轮询；实际记录保存在受保护目录。临时预览不冒充公网产品入口。

## 总目标与剩余顺序

交付国内公网 HTTPS 实际可用、智能化、经典功能完整、易用且有审美的数据中台。Data Agent 是独立任务工作台；经典模块保留独立操作与人工接管。GUI/API/CLI/MCP 共用身份、权限、资源、版本和结果。仅使用虚构中国证券案例，覆盖经纪财富管理及资产管理/基金；不公开公司材料、内部地址、真实业务数据或凭证。

月运行费用尽量不超过 ¥50，上限 ¥200；资源、模型、存储、流量及试用到期费用都应核算。预算告警不等于账号硬封顶，未取得当前完整账单不能宣称全站预算已核验。

后续顺序：

1. 当前 Agent 开发交付闭环与真实私有云验收。
2. DAPI/XAPI 开发、测试、授权、限流、版本、调用日志及真实结果消费。
3. 数据源/元数据、离线与实时同步、资产血缘、质量、安全脱敏、报表及运维等经典模块真实实现，逐模块接入 Agent。
4. 至少 20 条完整“理解需求 → 代码 → 调试 → 调度 → 部署 → 上线 → 监控”独立评测，至少 17 条成功；不能以 SQL 跑通率代替。
