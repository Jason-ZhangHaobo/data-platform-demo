# M4f：数据集快照、聚合报表与受治理问数

日期：2026-09-15。当前只使用本机虚构证券资产与已验证发布结果；报表没有公网分享、真实用户会话或生产BI引擎。

## 产品语义

1. 数据集草稿只保存资产和字段选择；显式刷新才把实际行物化到独立`v2-reports.sqlite`，平台库只留快照摘要。
2. 报表版本固定一个数据集快照；数据集后续刷新不会改写旧报表运行证据。
3. 首版只支持KPI、BAR、PIE，以及SUM、COUNT_DISTINCT、COUNT_ROWS；金额按整数分精确计算。
4. 报表结果与CSV只包含聚合值。client_id维度部分脱敏、position_id全遮盖；已有历史运行在读取时也应用显示层脱敏，底层证据不改写。
5. Agent只读取就绪数据集的字段、行数、快照摘要和已有报表摘要；后端验证每个组件，人工应用只创建草稿。
