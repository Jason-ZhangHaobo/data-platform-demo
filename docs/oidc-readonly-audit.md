# OIDC 只读检查合同

本检查用于验证既有部署身份能否读取指定控制面；不执行部署、触发器变更、函数调用、模型或计算任务，也不修改 IAM。实际运行结果与资源标识仍仅保留在受保护执行记录。

## 边界

- 只允许 main 手动触发，使用既有 v2-staging Environment、角色和 OIDC Provider；不新建身份或授予权限。角色与 Provider 必须属于同一账号。
- 依次执行 `sts GetCallerIdentity`、指定函数的 GET、该函数的触发器列表 GET。列表最多3页/20项，拒绝重复分页标记、重复项目和不完整结果；分页标记只用于同一函数的编码查询参数。身份不匹配立即停止；函数读取失败不继续枚举触发器；不自动重试。每次命令最多25秒，整个工作流最多5分钟。响应格式、分页未完成和权限拒绝分别记录，不输出原始错误内容。
- 不加载应用模型密钥、数据库密码等 GitHub Secrets；读取函数响应时仅在内存处理，输出前丢弃原始环境值。错误只保留固定分类，不输出原始响应、stderr 或异常堆栈。角色/账号/函数标识在获取凭证前加入日志遮罩。
- 触发器名称仅保留摘要，实际参数与函数状态写入加密报告；临时RSA私钥仅留操作者本机，工作流只接收公钥。报告使用AES-256-GCM和RSA-OAEP-SHA256，并绑定run编号、源码版本；密文Artifact保留1天。下载后先核实工作流run/源码，再在本机解密，不将解密结果提交仓库。
- “工作流成功”表示加密报告已生成，不代表每个云端检查均通过。必须读取报告内identity/function/triggers各自状态。读权限通过不代表具有创建、删除触发器或调用函数权限，更不代表应用端到端验收通过。

后续真实变更必须沿用用户具体授权、月度预算和最小权限。遇到权限不足只报告准确动作，不为绕开 OAuth 故障自动扩大角色权限；不通过打印密钥、改用长期密钥或公开原始日志排障。

测试入口：`test/v2/oidc-readonly-audit.test.mjs`。本机合成测试不算云通道验收。
