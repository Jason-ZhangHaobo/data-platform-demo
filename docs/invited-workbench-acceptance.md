# 受邀云端工作台接线与版本冻结

本合同服务于公网 Data Agent 标杆交付，不代表云部署或浏览器验收完成。

## 环境与权限

- 临时预览的HTML标记只约束预览通道范围，不决定服务端运行在本机还是云端，也不授予权限。
- 普通HTTPS页面从状态API的运行模式、数据服务开关及范围选择后端。受邀云端不能因为缺少预览标记而调用本机发布批次接口。
- Agent内的云数据服务接管和经典服务模块使用同一个后端判断；前者保留原任务编号，只选择该任务的实际发布来源。
- 服务写操作单独检查SERVICES权限，不继承父级AGENT模块的写权限。后端原有会话、项目、CSRF、所有权与版本审批检查不变。
- 未读取状态、能力关闭或模式不明时不猜测后端、不自动创建资源，也不回退本机接口。
- 本机人工交付只能在服务端明确的本机模式使用；云端人工版本未接入交付时如实提示，不能借用原Agent的审批。
- 私有预览仍受原模块白名单限制；邀请云端入口不因此获得“生产已验收”标记。现有虚构数据测试范围标签保留。

## 创建请求恢复

私有代理允许已启用的持久Agent读取原创建请求编号。只允许精确GET路径，拒绝额外查询、路径穿越、任意请求头和POST执行；内层API继续验证原会话与资源所有权。恢复查询不能调用模型或创建第二个任务。

## 验证与发布门

`test/v2/workbench-environment.test.mjs`验证模式、服务权限、两处实际接线及真实组件静态渲染；`test/v2/private-application.test.mjs`覆盖实际本机HTTP代理的原请求读取和未登录拒绝。这些测试不替代浏览器点击、视觉布局或云端业务验收。

冻结流程：比较本机/main/已部署业务文件 → 集中修复必要接线 → 定向与完整CI → 固定main SHA构包 → 记录包摘要/字节及回滚依据 → 获得阶段授权 → 私有部署与验收。无源码变化不重复构包；没有可验证的回滚产物不更新云函数。

## 仅代码更新保护

`scripts/control-code-update.mjs`是适配器驱动的更新策略，不持有凭证、不直接联网，不管理IAM。它本身不是已接通云端的部署命令。实际传输必须复用受保护通道，取得当前授权后才可执行。

- 应用源码与操作脚本源码分别记录。配置、目标、包摘要/字节/对象键、授权窗口及请求上限均绑定原检查点；恢复时不能换包、延长窗口或提高上限。
- 更新前须取得并独立验证原代码字节，确认两个不可变私有对象、预算及当前配置；更新请求只有`code`字段，不修改环境、Worker、网络、容量和触发器。
- 保存写前检查点；响应丢失后只读回查，不盲目重发。仅在仍为本次候选代码且受保护配置未漂移时，允许一次原包回滚。损坏回执、外来代码或配置变化均不能触发覆盖。
- 固定探测仅覆盖私有状态、应用状态、匿名会话及匿名拒绝读取；必须验证应用协议封装，网关HTTP状态不能替代应用结果。未配置执行能力不得因本阶段通过而标为模型/Spark可用。
- 此策略不开放公网、不创建业务任务，不执行模型或Spark，也不代替IAM清理和真实云端验收。

`test/v2/control-code-update.test.mjs`覆盖故障、恢复、范围绑定和实际回环HTTP合同。HTTP合同使用真实应用路由与权限检查，但云持久化和FC写操作仍是替身，不应称为真实云部署验证。

执行接线为`scripts/control-code-transport.mjs`与`update-v2-control-code.yml`：只允许受保护main和明确阶段批准，目标通过临时加密Secret传入并在获取OIDC前遮罩；下载原构包Artifact并核对摘要/大小，签名下载旧代码仅允许对应地域OSS且强制HTTPS。对象只允许两个精确包、create-only私有写入及字节回读/ACL验证，桶隐私须有当前受保护预检证据。CLI禁止自动重试，恢复不重新提交未知写入，最终只上传加密证据。工作流不管理IAM，临时权限及Secret由受保护本机协调过程回收。

对象创建不发送ACL修改头，默认继承已经核验的私有Bucket；写后仍必须读取对象ACL核验。`oss:GetObjectAcl`是独立只读权限，不由`oss:GetObject`隐含授权，须获两个精确对象的明确补充批准后才可执行；不申请`PutObjectAcl`或全桶权限。依据：[官方GetObjectACL权限说明](https://help.aliyun.com/zh/oss/developer-reference/get-object-acl)。

CLI的ROA路径不拼接查询字符串：列触发器用`--limit`，读代码/弹性配置用`--qualifier`独立传参。回归覆盖实际构造的参数列表，诊断区分函数读取、触发器列表、并发、弹性和旧包读取；CLI路径拒绝单独标记，不能作为网络或权限错误原样重试。本机CLI dry-run仅验证命令形状，不代表云调用成功。

官方接口依据：[取得旧代码](https://help.aliyun.com/zh/functioncompute/api-fc-2023-03-30-getfunctioncode)、[并发配置](https://help.aliyun.com/zh/functioncompute/api-fc-2023-03-30-getconcurrencyconfig)、[弹性配置](https://help.aliyun.com/zh/functioncompute/api-fc-2023-03-30-getscalingconfig)。弹性配置比较排除当前实例数等运行态字段，保留配置策略，避免正常缩扩实例被误当成配置改写。
